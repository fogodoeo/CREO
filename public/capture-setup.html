PRISM · 배송페이지 연동

낙찰 개체 자동 캡처

낙찰 완료와 동시에 본체에서 사진을 만들고 배송페이지의 해당 개체에 자동 연결합니다. 모든 값은 설정창에서 변경할 수 있습니다.

본체용 캡처 에이전트 받기
서버 상태 확인 중
1

PRISM 단축키 지정

PRISM 설정 → 단축키에서 출력 스크린샷을 Ctrl + Shift + F12로 지정하고, 출력 → 녹화 저장 경로를 확인합니다.

2

본체 에이전트 설치

압축을 풀고 install.bat을 실행합니다. 설정창에서 서버 주소, 채널, 관리자 비밀번호 또는 전용 캡처 토큰, PRISM 저장 폴더를 입력합니다.

  • 연결 테스트를 누릅니다.
  • PRISM을 켠 상태로 캡처 테스트를 누릅니다.
  • 성공 화면을 확인하고 저장합니다.
3

노트북 경매 앱 설정

경매 앱 → 설정 → 낙찰 자동 캡처에서 기능을 켜고, 본체 에이전트와 같은 서버·채널·토큰을 입력한 뒤 연결 테스트를 누릅니다.

4

실전 동작 확인

테스트 개체를 낙찰 처리하면 배송페이지에 촬영 대기 → 촬영 중 → 사진 순서로 표시됩니다. 사진의 재촬영 버튼으로 언제든 새 이미지로 교체할 수 있습니다.

5

사진 포함 문자

업체가 배송페이지에서 사진 포함 문자를 누르면 개체 사진이 클립보드에 준비되고 해당 고객 번호와 안내 문구가 입력된 문자창이 열립니다. 문자창에서 붙여넣기 후 전송하면 됩니다.

본체 에이전트의 자동 캡처, 단축키, 저장 폴더, 촬영 지연, 화질, 최대 폭과 크롭 영역은 바탕화면의 CREO 캡처 설정에서 변경할 수 있습니다. 캡처 실패는 낙찰 완료나 배송 저장을 막지 않습니다.
