PRISM · 배송페이지 연동

낙찰 개체 자동 캡처

어떤 경매든 현재 활성 채널을 자동으로 따라가며, 낙찰 완료와 동시에 본체에서 사진을 만들고 해당 배송페이지의 개체에 연결합니다.

본체용 캡처 에이전트 v1.2.2 받기
서버 상태 확인 중
1

PRISM 단축키 지정

PRISM 설정 → 단축키에서 출력 스크린샷을 F3으로 지정하고, 출력에서 스크린샷 저장 경로를 확인합니다. F3을 녹화 시작·종료에 지정하면 사진 파일이 생기지 않아 연동되지 않습니다.

2

본체 에이전트 설치

압축을 풀고 INSTALL.cmd를 실행합니다. Python은 필요 없습니다. 캡처 인증값에는 관리자 비밀번호를 입력하고, PRISM 저장 폴더를 선택한 뒤 경매 채널은 auto로 둡니다.

  • 진단으로 서버·폴더·인증·단축키를 확인합니다.
  • PRISM을 켠 상태로 캡처 테스트를 누릅니다.
  • 이 PC를 활성 본체로를 누른 뒤 저장하고 닫기를 누릅니다.
3

노트북 경매 앱 설정

경매 앱 → 설정 → 낙찰 자동 캡처에서 기능을 켜고 경매 채널을 auto로 둡니다. 이후 컨트롤타워에서 활성 경매를 바꾸면 사진과 배송 데이터도 해당 경매로 자동 분리됩니다.

4

실전 동작 확인

테스트 개체를 낙찰 처리하면 배송페이지에 촬영 대기 → 촬영 중 → 사진 순서로 표시됩니다. 사진의 재촬영 버튼으로 언제든 새 이미지로 교체할 수 있습니다.

5

사진 포함 문자

업체가 배송페이지에서 사진 포함 문자를 누르면 개체 사진이 클립보드에 준비되고 해당 고객 번호와 안내 문구가 입력된 문자창이 열립니다. 문자창에서 붙여넣기 후 전송하면 됩니다.

여러 컴퓨터에 설치해도 활성 본체 한 대만 촬영합니다. 활성 본체가 꺼지면 온라인인 예비 본체가 자동 승계하며, 즉시 바꾸려면 새 본체에서 이 PC를 활성 본체로를 누르세요. 문제가 생기면 바탕화면의 CREO Capture Diagnostics와 CREO Capture Log를 열면 단축키 전송, 파일 생성, 서버 연결, 업로드 중 어느 단계에서 실패했는지 확인할 수 있습니다.
