# 송출·배치 디자인 검토 — 2026-09-15

상태: 로컬 구현 및 검증 완료. 2026-09-15 사용자 배포 승인, 운영 배포 진행.

## 범위와 기준

채널 설정, 방송 관리, P1/P2/P3 공용 송출, 공용 배치 편집과 연결된 문구 설정을 검토했다. `better-interface`의 여섯 영역과 `emil-design-eng`의 상호작용 지침을 사용했다. 구매자·업체·주관사 결제 페이지 및 구형 전용 송출 엔진은 이번 검토 대상이 아니다.

사용자 지정 기준:

- 송출 화면과 배치 요소 선택에서 옹동2 워터마크 제거. 업체를 식별하는 낙찰 로고는 유지.
- 모바일 영상 시청 기준: 큰 글씨, 한 정보당 한 줄, 짧은 문구.
- P2는 개체명과 우선 특성 3개까지 표시. 기존 특성 데이터는 보존한다.
- 긴 내용은 작은 글씨로 자동 축소하지 않는다. 한 줄로 제한하고, 선택한 요소의 내용이 넘치면 편집 화면에서 알린다.
- 방송 색상과 P3 집계 규칙은 독립적이다. 색상을 바꿔도 팀, 점수, 입찰 상태를 변경하지 않는다.
- 저장된 좌표·글자 배율·불투명도는 존중한다. 새 글자 크기에 비해 기존 박스가 좁으면 운영자가 폭이나 문구를 조절한다.

## 검증 기록

구현 위험: 중간, 배포 검증 등급: Release. 공용 송출 스타일 및 배치 편집 상태를 변경했고, 색상은 기존 버전 검증이 있는 채널 저장 API로 색상 필드만 보낸다. 서버의 입찰·낙찰·발송 처리 코드는 변경하지 않았다.

- `npm run check`: 통과.
- `npm test`: 670/670 통과. 당시 존재한 로컬 도도시 테스트 14개 포함.
- 마지막 HTML 스크립트 위치 수정 후 `node --test test/platform-pages.test.js`: 46/46 통과.
- 배포 전 최신 변경 전체로 `npm run check`, `npm test` 재확인: 통과, 670/670. PC `python -m unittest discover -p "test*.py"`: 189/189 통과.
- 신규 JS 5개 구문 검사, 변경 HTML/JS/CSS 엄격한 UTF-8 검사, `git diff --check`: 통과.
- 로컬 브라우저 작업 검증: 캔버스 좌표, 방향키·드래그, 미저장 값 보존, 503 저장 실패 후 재시도, 저장 중 추가 수정, 색상 409 충돌, 열려 있는 P1/P2/P3 색상 갱신, P3 높이, 다른 채널 격리. 브라우저 JS 오류 0건.
- 실제 Codex 미리보기 846px 폭에서 색상 메뉴의 경계 16~320px 확인. 메뉴 잘림 수정 후 화면 안에 표시된다.
- 외부 발송기를 연결하지 않은 임시 SQLite 데이터만 사용했다. 운영 경매 기록 및 실발송으로 테스트하지 않았다.

로컬 실행 및 화면 기록은 PC 저장소의 `scratch/checkout-redesign/studio-design-preview.cjs`, `studio-functional-check.cjs`, `studio-functional-report.json`, `studio-final-*.png`에 있다. `studio-before-*.png`는 변경 전 기준 화면이다.

판정: 위 범위의 로컬 디자인 검토를 완료했고 사용자가 배포를 승인했다. 배포 후 운영 상태와 정적 파일을 읽기 전용으로 검증한다. PRISM 최종 합성·실기기 시청은 별도 현장 확인 대상이다.
