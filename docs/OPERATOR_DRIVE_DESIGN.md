# 운영자 공용 파일함

2026-11-04. 운영 관리 → 방송 도구 → 공용 파일함. 모든 채널에서 같은 자료를 사용한다.

## 화면과 흐름

- 운영 홈의 `operator-home.css` 토큰을 사용한다. 어두운 배경, 기존 금색 기본 동작, Pretendard 계열, 8px 버튼 / 14px 패널 모서리.
- 상단에 현재 폴더 경로, 검색, 새 폴더, 파일 올리기를 둔다. 파일 목록은 이름 → 크기 → 수정일 → 다운로드 순서다.
- 업로드만 기본 강조 버튼으로 표시한다. 폴더 이동·이름 변경은 선택 후 표시된 도구로 처리한다. 모바일에서는 수정일을 숨기고 파일명을 줄바꿈한다.
- 파일 입력과 드래그 업로드를 함께 제공한다. 체크박스로 여러 항목을 이동·삭제할 수 있다. 모든 기능에 키보드 경로가 있다.
- 삭제는 확인 후 휴지통으로 이동한다. 복원 또는 다시 확인한 뒤 영구 삭제할 수 있다. 자동 삭제는 없다.
- 사용량은 이 파일함에 등록된 완료 파일의 합계이며, 기존 경매 미디어와 R2 계정 전체 사용량이 아니다.
- 이미지/MP4/WebM/음성은 재생 컨트롤이 있는 미리보기를 제공한다. 실행 가능한 문서와 SVG 등은 다운로드한다. 자동 재생은 하지 않는다.

## 저장과 보안

- 파일은 비공개 R2 `operator-drive/objects/<UUID>`에만 저장한다. 기존 개체 사진·배너·캡처 키는 읽거나 수정하지 않는다.
- 이름과 폴더 트리는 SQLite의 서명 보호 대상 행 `creo_v2::operator_drive::index`에 보관하고 기존 미러에 포함된다. 이동·이름 변경은 객체를 재전송하지 않는다.
- 메타데이터 변경은 CAS로 처리하며 오래된 이름/이동 요청은 revision으로 거절한다. 운영 서버 단일 인스턴스를 전제로 업로드/완료/삭제를 파일별로 직렬화한다.
- 업로드는 최대 20GiB, 8MiB 조각, 동시에 최대 2개 조각 요청. 요청은 같은 출처의 운영 API를 거쳐 R2 multipart로 전달한다. 브라우저에 스토리지 자격증명을 주거나 PUT CORS를 추가하지 않는다.
- 파일함 최대 항목 수는 20,000개다. 빈 파일은 거절한다. 페이지를 닫으면 자동 이어올리기는 하지 않으며 미완료 업로드를 목록에서 취소할 수 있다. 취소하면 multipart 조각을 삭제한다.
- 완료 전 조각 수·순서·각 크기 및 최종 객체 크기를 확인한다. 완료 응답 유실 후 재시도는 HEAD로 확인한다. 삭제 실패는 삭제 중 상태로 남아 재시도할 수 있고 복원은 막는다.
- 모든 API에 관리자 인증, 변경 요청에 출처·Content-Type 검증을 적용한다. 다운로드 주소는 관리자 확인 후 5분 만료 서명으로 발급한다. 한국어 파일명을 유지한다.
- R2/SQLite CAS가 없거나 읽기 전용 전환 모드이면 다른 저장소로 묵시적 대체 없이 이용 불가로 표시한다.

## 검증

`node --test test/operator-drive.test.js test/operator-shell.test.js`

`node tools/check-operator-drive-ui.cjs`는 임시 SQLite와 모의 객체 저장소에서 9MB 분할 업로드, 다운로드, 이동, 휴지통, 복원, 영구 삭제, 새로고침, 320–1440px 배치를 실제 Chrome으로 확인한다. 운영 R2 연동 증거와 전체 테스트 결과는 출시 검수 기록에 남긴다.
