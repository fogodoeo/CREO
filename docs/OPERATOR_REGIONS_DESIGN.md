# 업체 지역 관리

- 기존 checkout 색상 토큰과 broadcast-booking 컴포넌트를 사용한다.
- 활동 업체는 지역별로 묶고 지역 안에서는 가나다순으로 정렬한다. 지역 미등록 업체는 먼저 노출한다.
- 지역 제목에 업체 수를 표시한다. 사용 중지 업체는 접힌 별도 영역에 보존하며 활동 수에 포함하지 않는다.
- 업체 선택은 지역별 optgroup으로 구분한다. 목록의 업체 버튼을 누르면 동일한 수정 폼을 사용한다.
- 대화상자는 최대 720px, 모바일에서는 뷰포트 안에서 스크롤한다. 좁은 화면의 목록은 한 열로 전환한다.
- 터치 영역 44px 이상, 기존 포커스 표시와 저장 결과 role=status를 유지한다.
- 중복 연락처만으로 지점이나 과거 회차 기록을 합치거나 삭제하지 않는다.
