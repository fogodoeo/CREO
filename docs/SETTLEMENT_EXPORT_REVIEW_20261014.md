# 총정산 내보내기 검증 · 2026-10-14

## 범위와 위험도

Release: 관리자 전용 정산 조회 API, XLSX 내보내기, 구글시트용 TSV 복사, 회원 정보 기반 낙찰자 전화번호 조회.
정산·알림 기록을 쓰지 않는 보고서이며, 입금 처리는 기존 주관사 화면을 사용한다.

## 화면 검토

| 영역 | 확인 결과 |
| --- | --- |
| 접근성 | 버튼 이름, 표 머리글, 상태 알림, 키보드 포커스, 가로 스크롤 영역 제공 |
| 배치 | 업체별 보낼 금액·기입금·미입금을 먼저 배치. 세부 열은 XLSX에 포함 |
| 문구 | 채널 누적, 미확정 배송비, 회원 정보 출처, 파일의 갱신 범위 구분 |
| 타이포그래피 | 금액은 숫자 정렬, 모바일 버튼 줄바꿈 제거 |
| 색상 | 잔액은 파랑, 실제 누락 항목만 주의 색상. 성공 메시지는 중립색 |
| UI | 360px 프레임에서 본문 clientWidth/scrollWidth 345/345. 4개 탭과 복사·다운로드 확인 |

## 보완한 오류

- 닉네임 이름 조회를 통해 다른 회원의 전화번호를 가져올 수 있던 금융 연락처 조회 경로를 회원 키 일치로 제한.
- 낙찰자를 수동 변경했을 때 이전 최고 입찰자의 번호가 사용되지 않도록 방어.
- 회원 정보에서 번호가 여러 개이거나 조회 실패 시 빈 번호와 확인 필요 상태 유지.
- 낙찰자·업체별 누적 결제 확인액을 개체마다 더하지 않음. 번호 미확인 개체는 같은 이름이어도 합치지 않음.
- 배송 미입력을 무료 배송 0원과 구분. 업체 미연결 또는 다른 낙찰자의 결제 기록이 있으면 보고서 생성 중단.
- 일반 출품료(유찰 포함), 낙찰 수수료, 이벤트 면제, 배송비 지원, 취소·환불을 각각 검증.
- 관리자 외 보고서 접근 차단. 원시 입찰 로그·회원 키·카드 결제 링크·접속 토큰은 내보내지 않음.

## 검증

- `node --test --test-isolation=none test/settlement-report.test.js test/band-membership.test.js test/national-settlement.test.js`: 최초 통합 30개 통과. 데이터 불일치 방어 추가 후 보고서 테스트 8개를 포함한 전체 검사 재실행.
- `npm test`: 1,121개 통과. 데이터 불일치 방어를 포함한 최종 변경 기준.
- `python -m unittest discover -p "test*.py"`: 203개 통과.
- `npm run check`, 새 JS 파일 `node --check`, HTML 인라인 스크립트 구문 검사, UTF-8 엄격 디코딩, `git diff --check`.
- 격리된 SQLite 데이터로 중복 조회, 입력 순서, 재시작, 채널·권한 경계, 디렉터리 실패, 잘못된 정산 원장, 보관 회차를 확인.
- 브라우저에서 XLSX 두 차례 다운로드와 TSV 복사 완료. 최종 XLSX를 Artifact Tool로 다시 열어 합계 재계산, 오류 검색 0개, 4개 시트의 5개 영역 렌더 확인.
- XLSX에 전화번호 텍스트 형식, 원 단위 숫자, 날짜 형식, 필터, 고정 행·열, 합계 수식 보존. 수식으로 시작하는 사용자 문자열은 실행되지 않도록 처리.

## 한계와 판정

검증 범위 내 배포 가능. 운영 기록은 테스트에 사용하지 않았다. 네이티브 Excel 앱 및 실제 Google Sheets에 업로드하는 검증은 하지 않았고, 파일 열기·재계산은 Artifact Tool과 SheetJS로 검증했다.
회원 명단에 정확히 연결된 전화번호가 없으면 자동 복구하지 않는다. 보관된 회차에는 현재 회원 명단의 번호를 적용하지 않는다.
내보낸 파일은 시점별 스냅샷이며 웹과 자동 동기화하지 않는다. 주관사 입금 원장은 업체별 누적이므로 회차별 입금 배분을 임의로 추정하지 않는다.
