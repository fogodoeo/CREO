# 업체 시즌 참가 확인

- 2026년 11월 시즌 전용. 11월 1일부터 2일 23:59:59(한국 시간)까지 대표 계정으로 응답한다. 마감 후 미응답은 그대로 유지한다.
- 업체별 최초 자동 안내는 서버에 기록한다. 기기를 바꾸거나 다시 로그인해도 반복하지 않는다. 닫으면 페이지 상단에 응답 진입 버튼을 유지한다. 직원은 상태만 확인한다.
- 참가 희망 / 불참은 한 번 제출한다. 불참은 자리 충원 안내 체크 후 확정한다. 제출 후 변경은 운영자 문의로 안내한다. 이미 배정한 예약이나 출품의 취소, 자리 충원은 운영자가 별도 확인하며 자동으로 실행하지 않는다.
- 업체 계정, 과거 거래, 정산, 배송, 기존 예약을 삭제하거나 보관 상태로 바꾸지 않는다. 다른 시즌에 응답을 재사용하지 않는다. 운영자 업체 로그인 관리 목록에 응답과 제출 시간을 표시한다.
- 기존 포털 Pretendard, 본문 #202632, 보조 #626d7b, 주요 버튼 #245bd4, 표면 #fff / #f1f5ff를 사용한다. 안내는 20px 제목과 15px 본문, 1.6 본문 행간, 44px 이상 버튼을 사용한다.
- 네이티브 dialog로 배경 비활성화와 키보드 탐색을 제공한다. Escape와 닫기, 나중에 응답은 같은 동작이다. 요청 중에는 중복 제출과 닫기를 막고 오류 후 재시도를 제공한다. 모션은 추가하지 않는다. 320px 폭에서는 버튼이 줄바꿈하고 팝업 내부가 세로로 스크롤된다.
