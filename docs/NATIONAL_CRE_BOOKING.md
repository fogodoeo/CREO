# 전국크레자랑 방송 예약

> 2026-09-22 초기 예약 구현 기록입니다. 현재 업체당 한도는 8마리이며 로그인·직원 참여·웹 적용과 최신 검증은 [NATIONAL_CRE_PORTAL.md](NATIONAL_CRE_PORTAL.md)를 따릅니다. 아래 로컬 검증 수치와 공개 전 목록은 초기 시점의 기록입니다.

## 적용 범위

채널 ID `national-cre`, `dataAdapter: platform`에만 활성화된다. 업체의 기존 출품 개체·낙찰/정산·업체 정보 네비게이션에 방송 예약을 추가한다. 다른 채널에는 노출하지 않는다. 관리자는 채널 운영 화면과 주관사 화면에서 방송 예약 관리로 진입한다.

이 작업은 로컬 구현이다. 운영 채널 생성, 배포, 운영 자료 변경, 실제 알림 발송은 하지 않았다. 기존 작업 트리의 다른 수정도 유지했다.

## 운영과 저장

- 월·수 20:00 한국 시간. 업체는 오늘부터 14일 후까지의 날짜를 선택한다. 서버가 요청 시 날짜를 계산하므로 별도 공개 작업이 필요 없다.
- 최소 32마리, 지역 합산 최대 16마리. 8개 지역의 인접 회차 중복을 금지한다. 지난 직전 방송과 미래 예약을 함께 검사한다.
- 지역 비트마스크의 가능한 편성을 시간순으로 연결해 검사한다. 각 인접 회차를 따로 검사했을 때 놓치는 편성 충돌도 막는다. 이는 지역별 이론상 수용 가능성일 뿐 실제 공급 확인이 아니다.
- 업체 지역은 운영자의 업체 지역 관리에서 등록하며 예약 시 자동 적용한다. 미래 예약이 있는 업체의 지역은 예약과 다르게 바꿀 수 없다.
- 신규 수량 예약은 즉시 확정한다. 임시 확보는 운영자의 변경 제안에 사용한다. 업체 수락 전까지 원래 예약과 제안 자리를 함께 유지한다. 같은 회차 증량은 차이만 확보한다. 거절·만료 시 제안 자리만 해제된다.
- `SQLitePlatformRepository.compareAndSwapRows`가 예약 상태, 요청 중복 처리 기록, 알림을 하나의 트랜잭션으로 저장한다. 별도 연결에서의 동시 요청, 재시도, 재시작을 검사했다. CAS 미지원 저장소는 예약 접수를 거부한다.
- SQLite 원본과 기존 미러 동기화 경로를 사용한다. 운영에는 기존 SQLite 영구 볼륨과 백업 설정이 필요하다.
- 확정 수량과 임시 확보를 분리 표시한다. 32마리 미달은 관리자가 모집하며 시스템이 다른 예약을 자동으로 이동·취소하지 않는다.
- 기존 업체 출품 목록의 개체를 예약에 연결한다. 화면의 개체 선택 수는 연결 개수이며, 개체 정보 전체의 완성도나 실제 경매 편성 완료를 뜻하지 않는다.

## 조절 가능한 설정

날짜별 최대 수량, 예약 마감 일시, 개체 선택 마감 일시, 업체 직접 변경·취소 마감 일시, 변경 요청 기본 응답 시간, 신규 접수 중지를 설정할 수 있다. 기존 확정·임시 확보와 충돌하는 설정은 저장되지 않는다. 지난 회차는 기록 열람만 제공한다.

초기 기본값은 최대 128마리(8지역 × 16의 이론상 상한), 예약·직접 변경/취소 마감 72시간 전, 개체 선택 마감 24시간 전, 응답 24시간이다. **128마리는 운영자가 확정한 방송 정원이 아니다. 공개 전에 운영자가 실제 정원과 기한을 정해야 한다.** 기본값 변경은 기존에 생성된 회차 설정을 보존하며, 개별 회차는 날짜별 설정에서 바꾼다.

업체별 미래 공급량 수집과 신규 임시 예약 모드는 이번 구현에 포함하지 않았다. 현재 확인되지 않은 공급량을 확보 물량으로 표시하지 않는다.

## 알림톡 연결

`broadcast_booking_updated` 한 종류로 예약 확정, 변경 제안, 변경 확정, 취소를 안내한다. 개체 등록 독촉과 방송 전 알림은 추가하지 않았다. SMS 대체 발송도 하지 않는다.

승인 전에는 알림을 `configuration_pending`으로 보존하고 운영 화면에 설정 대기를 표시한다. 승인 코드를 임의로 지정하지 않는다. 아래 초안은 승인 완료 자료에 포함되지 않는다.

- 초안: `docs/booking-alimtalk-draft.json`
- 승인 후 실제 코드·본문·버튼을 `ALIGO_KAKAO_TEMPLATES_JSON`의 `broadcast_booking_updated` 항목에 연결한다. JSON 전체를 덮어쓸 때 기존 템플릿 항목을 보존한다.
- 예약 링크: `/r/#{예약접속코드}`. 방송 후 30일까지 결과를 확인할 수 있다. 링크는 업체 인증 수단이므로 공유하지 않는다. 다른 업체의 예약은 읽거나 수정할 수 없다.
- 변경 제안 알림에는 기존 예약을 표시하며 상세 화면에서 변경 전후와 응답 기한을 비교한다.
- 오래된 상태 알림, 만료·거절된 변경 제안은 발송 직전 중지한다. 연락처가 변경된 경우도 기존 수신자로 발송하지 않는다.

## 공개 전 남은 작업

1. 전국크레자랑 운영 채널을 `national-cre`로 구성하고 업체 지역과 회차별 정원·마감 시각을 설정한다.
