# 파르게 예약 확인 알림톡 · 2026-11-01

파르게 예약 완료 → CREO에서 예약 완료 확인 → 낙찰자별 미리보기 → 예약확인 톡 보내기.
예약 완료는 실제 발송 처리나 결제 상태를 변경하지 않는다.

## 예약 완료 확인 · 주문번호 제외

사용자 요청으로 주문번호 불러오기·수령인별 연결·알림톡 주문번호 항목을 제거했다. 접수 묶음의 수령인·거점·마릿수를 보여주고 모두 파르게에서 예약 완료했는지 확인한 뒤 저장한다. 확인된 일정 입력은 선택 사항으로 접어 두며, 저장 후 바로 톡 미리보기로 이동한다. 이 확인 과정에는 확장 프로그램이 필요하지 않다. 기존 장바구니 자동 입력에는 계속 기존 도구를 사용한다.

서버는 개체 ID 구성과 최신 낙찰·배송 정보를 대조하여 예약 시점의 상태를 저장한다. 재낙찰·배송 변경·다른 회차·오래된 확인 창은 거절한다. 기존에 연결했던 주문번호는 감사 기록과 중복 방지 키를 보존하기 위해 내부에 남기지만 화면·알림톡에는 표시하지 않는다. 기존 메모만 있는 예약 기록은 간단한 예약 완료 확인을 한 번 거쳐야 알림톡을 보낼 수 있다.

## 일정

- 전국크레자랑 채널의 크레오 대구본점 출발에만 월요일 방송 → 화요일 특별 출발을 적용한다. 화요일 노선부터 도착지별 배송 요일을 계산한다.
- 수요일 방송은 출발 거점의 다음 정기 수거일과 도착지별 다음 배송일을 적용한다.
- 파르게에서 확인해 입력한 수령 예정일이 있으면 해당 날짜를 우선한다. 맡김일을 수령 예정일로 복사하지 않는다. 출발일과 수령일을 모르면 날짜를 임의 확정하지 않고 최신 일정 또는 `일정 확인 중`을 쓴다.
- 공개 운송 일정이 3일 이상 오래되거나 거점이 불분명하면 예상 날짜를 제공하지 않는다.

## 발송·운영

`buyer_parge_booking_confirmed`는 아직 승인 코드가 없는 초안이다. 기존 `UN_1912`는 주문번호가 포함된 검수중 템플릿이며 알리고가 검수중 수정 기능을 제공하지 않는다. 새 이름 `전국크레자랑 운송 예약 완료 안내`로 주문번호 없는 양식을 준비했다. 본문은 `config/kakao-alimtalk-templates.json`에 보관한다. 사용자 최종 확인 후 등록 신청하고, 새 승인 코드·본문을 `docs/approved-alimtalk/` 및 `approved-alimtalk.js`에 연결해야 활성화된다. 이전 `UN_1912`는 연결하지 않는다. SMS 대체 발송은 사용하지 않는다.

발송 요청과 알림 레코드를 같은 저장 트랜잭션으로 기록한다. 새 예약은 접수 기록 ID·정렬한 개체 ID에서 만든 이벤트 키로 동시 요청·재시작·재클릭의 중복 발송을 막는다. 기존 번호 연결 기록의 이벤트 키는 유지한다. 기존 발송 큐가 실패만 재시도하며 결과가 불명확하면 `delivery_unknown`으로 멈춘다. 발송 직전에 낙찰·연락처·거점·개체 구성·안내 날짜를 다시 검증한다. 변경된 알림은 만료시킨다. 실제 알리고 접수 완료와 최종 휴대폰 수신 성공은 다르다.

## UI 검수 기준

기존 `docs/CHECKOUT_DESIGN.md`와 `parge-dispatch.css`의 배경·표면·문자·파란 동작 색을 유지한다. 관련 better-layout/typography/colors/writing/accessibility/ui 기준으로 제목 아래 설명, 묶음별 fieldset/legend, 연결 입력, 최종 저장 순서로 구성했다. 44px 조작 영역, 16px 입력, 700px 이하 단열, 키보드 포커스, 오류 role=alert와 읽기 진행 role=status를 적용한다. 새로운 모션이나 디자인 토큰은 만들지 않는다.

## 검증 기록

- 주문번호 제외 변경: `npm run check`, `npm test -- --test-concurrency=4` 1,949개 통과. 주문번호 없는 예약 확인·누락 묶음 차단·동시 발송 및 재시작 중복 방지·저장 실패·재낙찰 검증을 추가했다. 격리 화면에서 확인 체크 → 저장 → 톡 미리보기 자동 이동을 확인했고, 320px에서 문서 너비 305px 및 주문번호 미표시를 확인했다. 데스크톱 재검증은 기존과 동일하게 136개 통과, niimprint 누락 1개 오류다. 알리고 새 양식은 최종 신청 전이며 기존 검수중 UN_1912는 수정되지 않았다.

- `npm run check`, 전체 웹 테스트 1,947개 통과, `git diff --check`, 변경 텍스트 UTF-8 검증 통과. 수동 출발일 예외 보완 후 재실행에서 기존 buyer-library-entry UI 대기 시험 1개가 일시 실패했으나 해당 파일 8개 단독 통과, 최종 전체 `npm test -- --test-concurrency=4` 1,947개 통과.
