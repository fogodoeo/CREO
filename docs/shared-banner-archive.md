# 공용 배너 정리

공용 안내 영상 교체 시 이전 버전이 보관함에 계속 남는 문제를 해결합니다. 정리한 배너는 목록과 송출 대상에서 제외하고, 동일 URL의 기존 채널 자료를 다시 가져와도 되살아나지 않습니다. 원본 레코드는 복원할 수 있도록 유지합니다.

관리자 API:

- `PUT /api/platform/banner-library/:id/archive`, JSON `{ "archived": true }`: 목록과 송출에서 제외.
- 같은 요청에 `false`: 복원. 기존 채널 선택 상태가 남아 있으면 다시 송출됩니다.
- `GET /api/platform/banner-library?includeArchived=1`: 정리된 배너까지 조회.

기존 업로드 재시도나 import는 정리 상태를 해제하지 않습니다. archive 변경은 공용 배너 변경 잠금을 사용하며 모든 채널의 송출 캐시를 무효화합니다. 일반 배너 선택과 다른 채널의 경매 기록은 변경하지 않습니다.

검증(2026-11-02): 중복 요청, 병렬 요청, 권한/입력 검증, 재가져오기, SQLite 재시작, 저장 실패, 복원, 송출 캐시 갱신 테스트 통과. npm run check 및 전체 1,962개 테스트 통과. 로컬 실제 배너 화면에서 정리한 구버전이 사라지고 선택된 새 배너만 남는 것을 확인했습니다.
