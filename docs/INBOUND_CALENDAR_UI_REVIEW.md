# 방송 달력 UI 검토

2026-10-05 · 로컬 4359 · 운영 미배포

## 범위와 결론

전국크레자랑 업체 방송 달력, 배송 마감 표시, 출발지 설정, 날짜 팝업을 검토했다. 로그인·낙찰·정산 화면 전체를 이번에 재검증한 것은 아니다.

문제는 방송 지역과 배송사를 비슷한 칸과 글자 무게로 보여줘 두 일정의 의미를 매번 읽어야 한다는 점이었다. 이름을 줄이고 모양을 분리했다. 사용자가 해야 할 개체 등록은 운송 설정보다 먼저 배치했다.

판정: 검토 범위 내 로컬 시안 **Approve**. 실제 휴대전화 및 보조기기 전체에 대한 적합성 인증을 의미하지 않는다.

## 영역별 검토

| 영역 | 검토 및 반영 | 확인 범위 |
| --- | --- | --- |
| 접근성 | 색 외에 배경·아이콘으로 구분. 날짜의 접근 가능한 이름에 방송 지역과 배송 마감을 함께 보존. 네이티브 선택 상자와 대화상자 사용. | 키보드 열기, Escape 닫기, 초점 복귀, AX 이름 확인. |
| 배치 | 달력 → 개체 등록 → 배송 마감 순서. 출발지 선택은 접어서 하위 단계로 배치. | 320px·390px 및 데스크톱 렌더링. |
| 문구 | 접수/맡기기 분리 명칭 제거. 파르게/도도시만 표시. 공통 의미는 배송 마감으로 표시. | 정상·미선택·운송표 상충 상태. |
| 타이포그래피 | 지역 12px/600, 달력 배송사 12px/400, 운송사 15px/600, 마감 날짜 18px/700. 선택 입력은 16px 유지. | 320px에서 배송사 이름 잘림·가로 넘침 없음. |
| 색상 | 기존 색상 체계 유지. 배송사 글자/흰 배경 5.26:1, 일반 지역 6.04:1, 우리 지역 6.07:1 대비. | 실제 렌더링의 계산된 색상으로 산출. 색만으로 상태를 설명하지 않음. |
| UI | 아이콘 선 두께 1.5px, 출발지 펼치기 및 안내 링크 44px 이상, 선택 입력 48px. 빈 오류 영역 제거. | 설정 펼침·저장·재렌더링, 날짜 충돌 및 팝업 상태. |

## 실행한 검증

- `node --check public/broadcast-inbound.js` 및 `node --check public/vendor-broadcast.js`: 통과.
- `node --test test/broadcast-inbound.test.js test/national-broadcast.test.js`: 18/18 통과. 격리된 테스트 데이터 사용.
- `git diff --check`: 통과. Git의 기존 LF→CRLF 안내 외 오류 없음.
- 수정 JS/CSS의 엄격한 UTF-8 디코딩과 U+FFFD 검사: 정상.
- 320px에서 배송사 글자 12px 표시, 가로 넘침 없음. 390px에서도 달력·마감일 영역 확인.
- 배송 날짜를 키보드로 열고 Escape로 닫으면 원래 날짜에 초점 복귀.
- 11월 2일 서울 방송과 도도시 마감이 같은 날에 표시됨. 접근 가능한 이름에 두 의미가 모두 있고, 팝업의 이날 방송 보기로 해당 방송에 진입 가능.
- 출발지를 당진 디어렙으로 선택하면 확인 링크 표시. 청주 디어렙으로 변경하면 10월 12일 마감 표시로 갱신되고 선택 상자 초점 유지.
- 우리 방송 지역명과 개체 등록 필요 작업이 함께 유지됨. 날짜 계산·출발지 저장 API는 이번 위계 수정에서 변경하지 않음.

## 남은 한계

- 실제 iOS/Android 기기, NVDA/VoiceOver, 브라우저 200% 확대는 이번에 직접 검증하지 않았다.
- 달력 7열 특성상 320px에서 날짜 칸 너비는 44px보다 작다. 글자 넘침 없이 세로 터치 공간을 확보했으나 실제 손가락 조작성은 기기 확인이 필요하다.
- 운송표가 상충하거나 임시 휴무가 있는 노선의 날짜를 새로 확정한 작업이 아니다. 해당 노선은 확인 링크로 남긴다.
- 운영 배포는 진행하지 않았다. 기존 전체 서버 959개 통과 기록은 이전 기능 구현 검증이며, 이번 표시 수정에서는 관련 18개만 다시 실행했다.
