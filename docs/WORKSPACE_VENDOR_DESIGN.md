# 채널 운영 업체 표

기존 Pretendard·밝은 배경·파란 강조색과 공통 버튼을 유지한다. 업체 탭에서만 본문 폭을 최대 1480px로 넓히고, 업체명 / 지역 또는 그룹 / 담당자 / 연락처 / 주소 / 계좌번호 / 관리 순서로 표시한다. 코드는 업체명 아래 보조 정보다.

- 전크자의 그룹은 방송 참여 지역이다. 운영자가 지정한 `broadcastRegion`을 우선하고, 기존 `bookingRegion`만 있는 경우 기존 8개 지역 매핑을 사용한다. 배송 주소로 지역을 추측하지 않는다. 방송 지역순, 같은 지역 안에서는 업체명순으로 정렬한다. 다른 채널은 기존 그룹과 순서를 유지한다.
- 담당자 `manager`를 우선 표시한다. 비어 있으면 `bankHolder`를 보여주되 반드시 ‘예금주 기준’이라고 표기한다. 담당자 기록을 예금주로 덮어쓰지 않는다. 둘 다 없으면 ‘미등록’이다.
- 은행명, 계좌번호, 예금주를 함께 보여준다. 주소·계좌번호는 말줄임 없이 줄바꿈한다. 누락된 정보를 임의로 채우지 않는다.
- 본문 14px, 업체명 16px, 헤더 13px, 보조 정보 12px. 보조 글자는 흰 바탕에서 대비가 확보되는 #596473을 사용한다. 숫자는 tabular-nums를 사용한다.
- 801–1140px에서는 가로 스크롤 안내를 표시한다. 800px 이하는 업체별 카드 형태로 항목명을 반복해 보여주며 원래 표의 제목·행/열 관계는 접근성 트리에 보존한다. 버튼 최소 높이는 40px이다.
- 기존 수정·삭제·업체 페이지·대표 로그인·주관사 연결 동작은 유지한다. 이 모듈은 인증된 운영 화면에 이미 전달된 데이터만 표시하며 공개 API나 접근 권한을 바꾸지 않는다.
