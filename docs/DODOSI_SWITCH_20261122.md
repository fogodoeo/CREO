# 신규 배송 도도시 전환 · 2026-11-22

사용자 확정 범위: 전크자·씨랩·쭌이네 신규 배송만 도도시. 기존 파르게 미발송 건도 자동 변경하지 않는다.

- 운영/준비 채널의 `shippingDefaults.enabledCarriers`를 도도시 한 개로 설정한다. 직수령·입금계좌·정산율·배송비 저장값은 유지한다. 전크자 다음 회차는 루트 설정을 상속한다.
- 새 채널 생성 기본값도 도도시다. 과거 설정 해석의 기본값은 바꾸지 않는다.
- 낙찰자는 도도시 거점을 바로 고른다. 파르게 미취급 지역 승인 절차는 도도시 전용 설정에서 사용하지 않는다.
- 기존 수령지는 선택지와 금액을 유지한다. 동일 수령지에서 결제 방법 등을 저장할 때 최신 요금으로 덮어쓰지 않는다. 삭제된 거점에 추가 개체를 임의로 무료 배송하지 않는다.
- 신규 회차 운영 홈에서 파르게 접수 메뉴를 감춘다. 지난 회차에는 ‘기존 파르게 접수 내역’을 유지한다. 배송 관리에는 도도시 실제 예약 페이지로 가는 새 창 링크를 둔다. 링크 열기는 예약 완료가 아니다.
- 업체 달력은 도도시 출품 운송 안내와 공식 거점·견적 링크를 제공한다. 이전 정적 수거 요일을 새 일정처럼 표시하지 않는다.

## 요금과 일정

도도시 공개 사이트가 Imweb에서 Next.js로 변경되었다. `/estimate` 공개 화면의 거점·배송 가능 대상·1마리 견적을 읽는다. 공개 화면에서 확인된 두 읽기 전용 action만 사용하며 주문·결제는 실행하지 않는다. 대구 크레용/광주 쭌이네 요금표는 출발지별로 분리한다.

응답 크기·시간 제한, 거점 수·중복·요금 합계 검사, 동시 요청 3개 제한을 적용한다. 일부 견적 실패 시 전체 갱신을 폐기하고 이전 자료를 유지한다. 실제 요금과 정산 할인액은 다르므로 파르게 할인율을 도도시에 복사하지 않는다.

공개 견적에 수거·도착일이 없어 `scheduleUnavailable`로 명시한다. 이전 요일표를 갱신된 일정으로 간주하지 않는다. 실제 일정은 도도시 예약/정거샵 확인이 필요하다.

## UI

기존 Pretendard, 공통 버튼·간격·포커스 스타일 유지. 새 디자인 토큰 없음. 신규 동작은 ‘도도시 예약’, 이력은 ‘기존 파르게 접수 내역’으로 구분한다. 기존 정산·문자·후원 로고는 운송사 설정과 별개로 보존한다.

## 검증

- `npm run check` 통과, 전체 `npm test` 2,088개 통과. 일정 표시를 끈 활성 채널과 준비 채널의 출발지도 요금 갱신에 포함하는 회귀 검사 추가.
- 운영·준비 채널 19개 신규 운송사 설정 적용 후, 기존 배송 기록 593건을 적용 전 해시와 비교하여 모두 동일함을 확인.
- 신규 파르게 요청 거절, 도도시 승인 없는 저장, 중복 저장·재시작, 기존 파르게 금액 보존, 폐지 거점의 기존 견적 유지 검증.
- 공식 공개 견적 실조회: 대구 크레용 출발 98거점, 광주 쭌이네 출발 101거점. 대구→광주 및 대구→제주 1/2마리 견적의 추가 개체료 7,000원 확인.
- 격리 SQLite/가상 연락처 미리보기: 구매자 320·390·1280px, 운영자 320px·1280px, 업체 출품 운송 안내 320px 확인. 확인한 화면의 가로 넘침·스크립트 오류 없음. 신규 예약 링크 높이 44px, 글자 14px 확인.
- 실제 주문·결제·문자 발송 없음. 공개 견적에 없는 수거일·도착일과 실제 도도시 예약 완료는 검증 범위 밖이다.
