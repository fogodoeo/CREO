# 업체 선택 및 첫 화면 진입 개선 — 2026-10-06

## 범위와 위험 분류

- 동일 계정에 연결된 도레미·셀렙을 선택하고 현재 메뉴에서 업체를 전환한다.
- 두 업체 ID, 로고, 연락처, 계좌, 출품, 낙찰·정산은 각각 유지한다. 회차당 출품은 **업체별 4~5마리**다.
- 관리자 사전 등록의 대표 로그인 번호와 인증된 번호가 일치하는 미연결 업체만 직접 연결 대상으로 노출한다. 일반 연락처 일치로 권한을 주지 않는다.
- 위험: **Release**. 업체 접근 권한 조회와 공개 짧은 링크의 초기 HTML 선택, 운영 배포를 포함한다. 경매 상태·결제·배송 계산을 변경하지 않는다.
- 운영 데이터로 테스트하지 않았다. 가상 업체, 가상 문자 공급자, 격리된 임시 SQLite를 사용했다.

초기 헤더 검증에서는 로컬 방송 API를 잠시 보류했다. 응답 전후 헤더의 x/y/폭/높이가 같았고 완료 후 보이는 헤더는 하나였다. 브라우저 오류·경고 로그는 없었다.

## 판정과 남은 확인

**Approve: 이번 코드·UI 변경 범위.** 재현한 높은 위험의 결함은 수정했고 해당 테스트가 통과했다.

- 실제 도레미·셀렙의 운영 대표 로그인 번호/소유권 상태는 운영자 로그인이 없어 미확인이다. 두 업체의 운영 연결이 완료됐다고 간주하지 않는다.
- 실제 휴대전화, 스크린리더, 브라우저 200% 확대 검증은 하지 않았다.
- 중복 조회와 중간 페이지 이동을 제거한 결과이며, 통신 지연이나 서버의 모든 대기 시간을 없앤다는 의미는 아니다.
- 배포 후에는 운영 건강 상태와 배포 정적 파일을 읽기 전용으로 확인한다. 운영 데이터로 로그인·출품·정산 변경 테스트는 하지 않는다.

로컬 재현 도구: `tools/vendor-switch-preview.cjs`. 테스트 데이터는 운영 데이터와 분리되어 있다.
