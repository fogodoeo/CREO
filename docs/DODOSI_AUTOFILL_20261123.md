# 도도시 자동 입력 · 2026-11-23

## 범위

신규 배송에만 적용. 기존 파르게 접수·배송비·낙찰금·결제·문자는 변경하지 않는다. 현재 출발/업체 입고 거점은 크레용(대구). 하이딩플레이스로의 전환은 아직 하지 않는다.

## 확인한 원본

로그인한 도도시 `/order` 화면의 정거샵, `deliverableAction`, `scheduleAction`, `quoteAction`만 조회한다. 동적으로 action ID를 찾아 사이트 변경 시 잘못된 요청을 보내지 않고 중단한다. 인증 쿠키·비밀번호를 복사하거나 서버에 저장하지 않는다.

- 정거샵 104개, 대구 기준 양방향 206개 조합 중 예약 가능 196개(편도 98개).
- 대구→서울 강동: 11/24 맡김, 11/25 수거, 11/28 도착 / 11/28 맡김, 11/29 수거, 12/2 도착.
- 대구→강원 일부 노선은 다음 일요일 수거다. 모든 지역을 수·일 고정으로 추정하지 않는다.
- 서울 강동→대구: 11/27 맡김, 11/28 수거, 11/29 도착. 11/30 방송 전 입고 가능.
- 현재 로그인 계정 할인 50%. 기본료+지역할증+추가개체료 합계에 적용. 2마리 35,000원 → 17,500원을 실제 화면에서 확인. 보험·쿠폰은 자동 추가하지 않는다.

## 시스템

- 공개 정상요금은 기존 서버의 일일 갱신 유지. 로그인 필요한 일정은 별도 캐시에 저장하여 공개 요금 갱신에 덮어써지지 않는다.
- 도도시 입력 도우미 설치 후, 로그인된 도도시 예약 탭과 CREO 배송 준비 페이지가 열려 있으면 페이지 진입 시 1일 지난 자료를 자동 갱신한다. 수동 갱신도 가능하다. 브라우저가 닫혀 있거나 로그아웃이면 인증 일정 자동 갱신은 불가능하다.
- 일정은 3일 초과 시 예상 날짜 대신 확인 필요로 표시. 불완전한 전체 노선 수집, 과거 자료 덮어쓰기, 요금 합계 오류를 거절한다.
- 낙찰자·업체 결제 확인 화면은 같은 일정 서비스 사용. 맡김·발송·수령 예정 구분. 업체 출품 운송은 실제 맡길 지점별로 방송 **전날까지 도착**하는 편 중 가장 늦은 맡김일을 안내한다. 당일 도착은 자동 승인하지 않는다.
- `/dodosi-dispatch.html?channel=...`: 회차별 보내는 분 저장, 낙찰자별 합배송, 정상/계정 할인 견적, 예약서 자동 입력. 동일 이름이라도 지점 ID가 다르면 합치지 않는다.
- 자동 입력 전 서버에서 최신 개체·수령인·결제 상태를 재검사하고 클라이언트에서 최신 예약 가능일/견적 재조회. 입력 시도는 예약·발송 완료로 기록하지 않는다. 최종 약관·결제는 사용자 확인.
- 확장 권한: 도도시 도메인만 scripting, CREO 도도시 준비 페이지에만 연결 스크립트. 저장된 계정 정보 없음. 한 명씩 새 예약서로 열며 기존 작성 중 폼을 덮어쓰지 않는다.

## UI 기준

기존 배송 운영 CSS의 색상·간격·16px 입력·44px 이상 버튼·포커스 사용. 모바일 카드는 한 열, 날짜는 맡김→수거→도착 순서. 지역 선택은 실제 정거샵 전체 이름을 표시한다. 새 브랜드 토큰을 만들지 않았다.

## 검증

- 실제 로그인 Chrome: 2마리 deep link, 맡김일, 크레스티드 선택, 보내는 분·받는 분 테스트 이름/전화 입력, 약관 미선택·결제 미실행 확인. 테스트 예약서는 닫았다.
- 격리 API: 관리자 권한, 중복 import, 이전 자료 거절, 동시 저장/입력 시도, 재시작, 타 채널 분리, 기존 배송비와 알림 불변 검증.
- 320/390px 운영 UI 및 업체 일정·낙찰자 일정, 데스크톱 1280px 확인. 자동 입력 확장 설치 상태의 전체 왕복 연결은 설치 승인 후 확인한다.
- 실제 예약·결제·알림 발송은 수행하지 않음.
