# 출품 접수번호와 경매 번호

- 업체의 `개체 1·2·3·4`는 접수 식별자다. 경매 번호를 뜻하지 않는다.
- 출품 검토의 새 경매 번호는 빈칸이며 운영자가 입력한다. 기존 번호는 유지한다.
- 번호 설정은 기본으로 펼친다. 입력칸은 `경매 번호`, 예시는 `A01`로 표시한다.
- 일괄 배정 버튼은 `선택 개체 자동 번호 배정`으로 명시한다. 추천·일괄 배정은 운영자가 직접 선택할 때만 실행한다.
- 새 번호에는 `1부·2부·이벤`을 붙이지 않는다. 저장 및 중복 검사에서 기존 `1부 A01`과 `A01`을 같은 번호로 취급한다. 기존 기록은 읽기만으로 바꾸지 않는다.
- 운영자 `unassign` 명령은 현재 회차의 입찰 이력이 없는 대기 개체만 처리한다. 접수·개체 ID, 사진, 정보, 내부 진행 순서와 시작가는 보존하고 경매 번호만 비운다. 항목 이름은 접수 식별자로 돌아간다.
- 번호 해제는 회차 잠금, 항목·접수 버전 검사, 중복 요청 기록과 원자적 저장을 사용한다. 진행·낙찰·보관 기록은 처리하지 않는다.

기존 검토 페이지의 공통 스타일과 오류 포커스를 유지한다. 미입력 번호는 저장을 막고 해당 입력칸으로 이동한다.
