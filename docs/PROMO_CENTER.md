# 전국크레자랑 홍보 관리

## 이용 경로
- 업체: 기존 업체 로그인 → 업체 선택 → 하단 홍보 관리. `/promo-center.html?company=<업체 ID>`
- 운영자: 채널 작업공간 → 홍보 일정 관리. `/promo-center.html?admin=1`
- 오후 13:30–14:55, 심야 23:30–23:55. 한국 시간, 심야는 표시된 날짜에 속함.
- 시간대별 기본 정원 1곳. 운영자가 1~10곳으로 변경 가능. 임의의 실제 업체 배정은 생성하지 않음.

## 저장·접근
- 기존 HttpOnly 업체 세션·대표/직원 소속·CSRF 검증 사용. 다른 업체 선택은 접근을 허용하는 수단이 아님.
- 운영자 API는 기존 관리자 인증을 사용. 모든 쓰기는 같은 Origin을 요구.
- 업체는 전체 달력과 원고별 사용 이력을 볼 수 있고, 자기 배정만 게시 완료 처리.
- 전크자 setting `promo-center`에 저장. 기존 SQLite/Supabase 미러와 CAS 원자적 갱신 사용.
- 각 변경 요청의 ID로 중복 효과 방지. 배정·원고·정원 수정은 revision 비교. 오래된 요청은 409.
- 복사 성공 이력과 게시 완료는 구분. 게시 완료는 업체가 제출한 URL이며 네이버 자동 검증이 아님.
- 자료에는 연락처·주소·인증값을 포함하지 않음. 내부 변경 로그의 actor는 업체 ID 또는 admin.
- 조회는 월 단위. 현재 저장 한도는 배정 5,000건, 요청 20,000건이며 한도 도달 시 기록을 삭제하지 않고 새 쓰기를 거절. 장기 운영 시 월별 보관 분리 필요.

## 원고
- `promo-templates.json`: 도입부를 복원한 인사형, 간결형 두 원고.
- 관리자가 추가·수정·복제·비공개 가능. 문단 텍스트·크기·굵기·강조색 수정.
- 이미지 3종은 기존 사용자가 만든 자산. 새 이미지 업로드 UI는 이 버전에 포함하지 않음.
- 인사형은 원문 옹동2 인사를 보존하므로 사용 업체에서 인사말 수정.
- 본문/제목 복사와 이미지 개별 다운로드. 복사 실패 때 사용 이력은 남기지 않음.
- 공개 본문에는 서울·인천을 반영했으나 기존 사진에는 서울 편 표기가 있음. 후속 원고 관리에서 지역 통합 배너로 교체 가능.

## 네이버 편집기 제한
- 실제 임시 작성창에 동일한 HTML을 붙여넣어 텍스트의 크기·색·굵기·정렬 및 네이버 이미지 URL 전달 확인.
- 로컬 이미지 주소는 제외되어, 복사 HTML에만 기존 Naver 호스팅 URL 사용. 화면 미리보기/다운로드는 자체 자산 사용.
- Naver는 글꼴을 기본서체로, 이미지 폭을 800px로 변경. 붙여넣은 뒤 전체 글꼴을 나눔스퀘어 네오로, 이미지 폭을 각각 500px로 지정해야 함. 완전 무수정 복제로 보장하지 않음.
- Naver 이미지 URL 수명이 보장되지 않으므로 자체 이미지 다운로드 대안 제공.
- 브라우저 도구의 가상 클립보드가 앱 Clipboard API와 분리돼 원고 버튼 → 네이티브 Ctrl+V 전체 경로는 미검증. 버튼 성공/사용 이력 저장, 동일 HTML을 도구로 붙여넣는 경로는 각각 확인.
- 원래 카페 초안은 수정하지 않았고, 시험용 작성창도 게시·임시등록하지 않음.

## 디자인·검증
- `CHECKOUT_DESIGN.md` 및 업체 공통 shell 유지. 밝은 배경/흰 표면/파란 주요 행동, Pretendard, 44px 버튼.
- 사용 흐름: 다음 내 일정 → 달력 → 원고 미리보기·복사 → 게시 링크 등록.
- `better-layout`, `better-typography`, `better-colors`, `better-writing`, `better-accessibility`, `better-ui` 적용. 자동 모션 없음.
- `node --test test/promo-center.test.js`: 인증·소속·CSRF, 동시 정원, 중복 요청, 재시작, 상태 경계, 저장 오류, 원고 검증.
- 전체 `npm test`: 1,008개 통과. `npm run check`, 신규 JS 구문 검사, `git diff --check` 확인.
- 격리 SQLite/가짜 SMS의 `node tools/promo-preview.cjs`: 업체/운영자 화면, 실제 배정 저장, 원고 복사 이력 확인. 운영 데이터와 연결되지 않음.
- 실제 IAB 기본 너비 화면 검수. 390px viewport 요청은 IAB 실제 크기에 반영되지 않아 모바일/200% 확대는 미검증. 스크린리더 음성 검증 미실시.
- 운영 사이트 배포 및 운영 인증 검증 전. 이 파일은 운영 배포 완료 보고가 아님.
