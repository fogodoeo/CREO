# 전국크레자랑 홍보 관리

## 이용 경로
- 업체: 기존 업체 로그인 → 업체 선택 → 하단 홍보 관리. `/promo-center.html?company=<업체 ID>`
- 운영자: 채널 작업공간 → 홍보 일정 관리. `/promo-center.html?admin=1`
- 오후 13:30–14:55, 심야 23:30–23:55. 한국 시간, 심야는 표시된 날짜에 속함.
- 시간대별 기본 정원 1곳. 운영자가 1~10곳으로 변경 가능. 임의의 실제 업체 배정은 생성하지 않음.

## 저장·접근
- 기존 HttpOnly 업체 세션·대표/직원 소속·CSRF 검증 사용. 다른 업체 선택은 접근을 허용하는 수단이 아님.
- 운영자 API는 기존 관리자 인증을 사용. 모든 쓰기는 같은 Origin을 요구.
- 업체는 전체 달력과 원고별 사용 이력을 볼 수 있고, 자기 배정만 게시 완료 처리.
- 전크자 setting `promo-center`에 저장. 기존 SQLite/Supabase 미러와 CAS 원자적 갱신 사용.
- 각 변경 요청의 ID로 중복 효과 방지. 배정·원고·정원 수정은 revision 비교. 오래된 요청은 409.
- 복사 성공 이력과 게시 완료는 구분. 게시 완료는 업체가 제출한 URL이며 네이버 자동 검증이 아님.
- 자료에는 연락처·주소·인증값을 포함하지 않음. 내부 변경 로그의 actor는 업체 ID 또는 admin.
- 조회는 월 단위. 현재 저장 한도는 배정 5,000건, 요청 20,000건이며 한도 도달 시 기록을 삭제하지 않고 새 쓰기를 거절. 장기 운영 시 월별 보관 분리 필요.

## 원고
- `promo-templates.json`: 도입부를 복원한 인사형, 간결형 두 원고.
- 관리자가 추가·수정·복제·비공개 가능. 문단 텍스트·크기·굵기·강조색 수정.
- 이미지 3종은 기존 사용자가 만든 자산. 새 이미지 업로드 UI는 이 버전에 포함하지 않음.
- 인사형은 원문 옹동2 인사를 보존하므로 사용 업체에서 인사말 수정.
- 본문/제목 복사와 이미지 개별 다운로드. 복사 실패 때 사용 이력은 남기지 않음.
- 공개 본문에는 서울·인천을 반영했으나 기존 사진에는 서울 편 표기가 있음. 후속 원고 관리에서 지역 통합 배너로 교체 가능.

## 네이버 편집기 제한
- 실제 임시 작성창에 동일한 HTML을 붙여넣어 텍스트의 크기·색·굵기·정렬 및 네이버 이미지 URL 전달 확인.
- 로컬 이미지 주소는 제외되어, 복사 HTML에만 기존 Naver 호스팅 URL 사용. 화면 미리보기/다운로드는 자체 자산 사용.
- Naver는 글꼴을 기본서체로, 이미지 폭을 800px로 변경. 붙여넣은 뒤 전체 글꼴을 나눔스퀘어 네오로, 이미지 폭을 각각 500px로 지정해야 함. 완전 무수정 복제로 보장하지 않음.
- Naver 이미지 URL 수명이 보장되지 않으므로 자체 이미지 다운로드 대안 제공.
- 브라우저 도구의 가상 클립보드가 앱 Clipboard API와 분리돼 원고 버튼 → 네이티브 Ctrl+V 전체 경로는 미검증. 버튼 성공/사용 이력 저장, 동일 HTML을 도구로 붙여넣는 경로는 각각 확인.
- 원래 카페 초안은 수정하지 않았고, 시험용 작성창도 게시·임시등록하지 않음.

## 2026-10-07 사용 흐름 보완 및 출시 점검

- 업체의 미완료 일정을 월과 관계없이 상단에 표시. 지난 일정도 완료 등록 전까지 유지. 원고 복사와 완료 등록을 같은 카드에서 제공.
- 배정에서 사용하는 원고의 비공개 전환 차단. 중복 게시 URL의 모바일 호스트·추적 파라미터·끝 슬래시를 정규화.
- 오래된 월 조회 응답이 최신 화면을 덮지 않음. 복사 중 연타 방지, 복사/팝업 종료 후 키보드 포커스 복구.
- 로딩·로그인 만료·저장 성공 후 조회 실패를 구분. 저장 오류 시 입력 유지. 충돌 시 명시적인 입력 취소/최신 조회 제공.
- 검증: 서버 전체 1,010개 및 집중 7개 통과. 동일 임시 SQLite 실제 UI에서 잘못된 게시 URL 거절 → 올바른 URL 등록 → 새로고침 후 완료 상태 유지 확인. 카페 게시나 실제 고객 알림은 실행하지 않음.
- UI 검수 범위: 업체 달력/원고/복사/완료 흐름과 운영자 배정. 기존 밝은 배경·파란 행동색·공통 업체 내비게이션 유지. 레이아웃/문구/대비/타이포/키보드 포커스/정적 상태 검수. 자동 모션 없음.
- 운영 배포 전 health: ok=true, durable=true, outboxPending=0, mirrorError=null.
- 별도 PC 앱 저장소는 이 환경에서 찾지 못해 PC 회귀 테스트 미실시. 이번 변경은 새 웹 API와 업체 웹 화면에 한정되며 PC 경매 프로토콜/출력은 수정하지 않음.
- 운영 반영 허가는 사용자의 “확실하게 작동하고, 편의성 충분히 고려된 형태로 ㄱㄱ”에서 확인. 배포 후 정적 파일과 비로그인 접근 차단을 읽기 전용 검증한다.

## 전국노래자랑 감성·참여업체 원고와 썸네일

- `launch26-showtime`: 얼굴 없는 실사 연출, 마이크를 든 진행자와 작은 크레. 사용자가 애니메이션 대신 실사로 변경을 요청하여 최종 원고에는 실사만 사용. 실제 출연자/출품 개체가 아닌 AI 연출임을 본문에 표시.
- `launch26-partners`: 2026-10-07 운영 업체 수정 화면에서 확인한 등록 25곳 중 로고 22곳을 원형 그대로 사용. 오늘도마뱀/오케이게코/니코게코는 로고 미등록으로 이름 표시. 원본 출처는 `tools/promo-partners.json`, 제작 코드는 `tools/build-promo-extra.cjs`.
- 업체 로고판은 생성 모델에 맡기지 않고 등록 원본을 그대로 SVG 레이아웃에 배치한다. 회차별 순차 출연 문구로 동시 출연으로 오인되지 않도록 한다. 실제 등록업체 목록이므로 미등록 참가 예정 업체를 임의로 추가하지 않는다.
- 카드 목록은 이미지/스타일/제목/도입부/사용 이력으로 선택을 돕는다. 이미지와 하단 버튼 모두 전체 원고를 연다. 모든 기존 원고에도 작은 WebP 미리보기를 제공하며 원본/텍스트 대체가 있다.
- 서버 인증/일정/쓰기 로직은 변경하지 않음. 기존 번들 병합 검사 8개와 전체 1,011개 통과. 썸네일/원고 UI 및 생산 사이트 읽기 검증 결과는 별도 검수 기록에 저장한다.
- 로컬 실제 화면: 1024/390/320px 카드 9개 가로 넘침 0, 버튼 높이 44px 이상. CSS 200% 확대에서 카드 넘침 없음. 썸네일 Enter → 미리보기 → Escape 포커스 복귀/포커스 테두리 확인. 새 원고 2개 이미지 로드, 500px 원본 폭, 복사 성공 확인. 작은 이미지 실패→원본→텍스트 대체 확인 후 임시 DOM 변경 복구.
- 본문/보조 글자/포커스 파랑의 흰 배경 대비는 각각 15.17/5.26/5.96:1. 실제 기기·스크린리더 음성·새 자산의 네이버 편집기 붙여넣기 전체 경로는 미검증. PC 앱 저장소가 없고 PC 프로토콜 변경도 없어 별도 PC 테스트 미실시.
- 후속 사용자 제공: 오늘도마뱀/니코게코/오케이게코/크레버디 원본을 반영하고 도레미·셀렙을 개별 표기하여 현재 로고판은 **27개 브랜드**. 위 22개 확인 기록 이후 확장한 결과이며 실제 업체 등록/소속은 변경하지 않는다. 조합 로고는 SVG 뷰포트로 분리 표시하고 원본 픽셀은 보존한다. 화이트 배경, 일정한 표시 영역과 보통 굵기의 업체명, 간결한 헤더로 정리. 기존 미등록 로고 안내는 제거.
- 로고별 표시 보정: 도레미·셀렙은 동일한 196×196 검은 정사각형 안에 비율을 유지해 중앙 배치. 오케이게코는 원형 클리핑으로 외곽 검은 배경을 제외하고, 제트크레는 위아래 검은 여백을 크롭한다. 로고 자체를 늘이거나 다시 그리지 않는다. 보정값은 `tools/promo-partners.json`에 저장하여 재생성 시 유지한다.

## 참여업체 갤러리 디자인 정리

- 3열의 큰 원본 로고와 여백을 중심으로 정리했다. 업체명은 Pretendard 500 한 가지 위계로 통일하고 배지·칸 구분 장식을 사용하지 않는다. 큰 헤더와 차분한 캡션으로 시선의 순서를 만든다.
- 흰 배경, 본문 #202632, 보조 #626d7b, 브랜드 표기 #007443. 기존 로고 색상은 그대로다. 원본의 무게에 따라 228/252px로 크기를 보정하되 비율을 유지한다. 도레미·셀렙은 동일한 검은 정사각형을 유지한다.
- tools/render-partner-board.cjs가 1500px 원본과 27개 로고를 모두 보여주는 미리보기를 생성한다. 서체는 기존 배포 WOFF2를 사용하고 SVG 내부에 렌더링하여 환경별 글꼴 대체를 피한다.
- 로컬 실제 원고 미리보기에서 본문과 500px 이미지 폭, 하단 로고·업체명 배치, 새 썸네일을 확인했다. 모바일에서 작은 로고 안의 원본 글자까지 읽기 좋다고 보장하지 않으며 업체명 캡션을 함께 제공한다.
### 교체 이미지 캐시

## 2026-10-07 원고 닫기 및 안내 배너 개선

- 원고 미리보기와 수정 창은 제목·닫기 버튼을 고정 영역으로 두고 본문만 스크롤한다. 미리보기의 복사 버튼도 계속 보인다. 기존 서체·색상·44px 조작 영역을 유지하고 자동 모션은 추가하지 않는다.
