- 기존 흰색 표면·본문/보조색·파란 기본 행동색과 44px 버튼을 재사용한다. 제목 20px, 항목 16px, 설명 14px, 시간 24px의 위계다. 540px 이내 모달에서 본문만 스크롤하고 닫기·확인 버튼은 유지한다. native dialog의 키보드 포커스 제한·Escape, 바깥 클릭 닫기·포커스 복귀를 지원하고 진입 애니메이션은 추가하지 않는다.
- 배정 원고 바로가기에서는 안내를 닫은 다음 해당 원고를 열어 모달이 겹치지 않게 한다. 안내는 복사할 원고에 포함하지 않는다.

## 2026-10-09 전체 업체·비로그인 원고 복사

- 업체 페이지 상단의 `홍보 원고 전체 보기·복사`는 로그인·업체 연결·게시 일정 배정 없이 `/promo-center.html?library=1`의 공개 원고 목록을 연다. `company`와 `admin` 없는 기본 원고 주소도 같은 목록을 연다.
- 공개 목록은 운영자가 공개 중인 전체 원고를 제공한다. 이전에 반려·보관한 원고는 복구하지 않는다. 제목·서식 있는 본문·글만 복사와 전체/지역별 업체 로고 선택을 기존 미리보기로 제공한다. 처음에는 전체 참여업체를 선택한다.
- `GET /api/platform/promo-library`는 허용된 원고 필드와 업체 권역별 수만 반환한다. 배정·게시 URL·복사 이력·감사 로그·업체 연락처·계좌는 포함하지 않는다. `/partners`는 정해진 전체/권역 선택과 최신 명단 버전에 대해서만 기존 공개 이미지 캐시를 사용한다. 원고/일정 변경 및 업체 관리 API의 인증·소속·CSRF 조건은 그대로다.
- 비로그인 복사는 업체 사용 이력이나 게시 완료로 기록하지 않는다. 로그인한 업체의 기존 홍보 관리는 사용 이력·일정 확인을 유지하며, 배정 카드의 `전체 원고 보기·복사`로 다른 원고를 바로 고를 수 있다.
- 디자인: 업체 공통 `.choice` 표면, 기존 서체·색상·44px 이상 조작 영역을 유지한다. 공개 목록에서는 달력·배정·사용 이력을 숨기고 원고 선택을 첫 흐름으로 둔다. 모바일 카페 앱의 이미지 누락 안내는 유지하며 일괄 붙여넣기 호환성이 개선됐다고 표시하지 않는다.
- 검증: 관련 36개 및 전체 1,067개 테스트, `npm run check`, UTF-8 검사 통과. 공개 필드 제한·관리 접근 거절·운영자 수정/보관 반영·재시작·동시 로고 생성 재사용·실패 복구·익명 복사 무기록을 검사했다. 로컬 실제 화면에서 비로그인 업체 페이지 → 전체 9개 원고 → 기본 전체 로고 → 제목/본문 복사, 320/390px 가로 넘침 없음, 44px 복사 버튼, Escape 후 포커스 복귀를 확인했다. 실제 휴대폰 카페 앱 붙여넣기는 미검증이다. 별도 데스크톱 앱 계약은 변경하지 않았다.

## 2026-10-09 모바일 카페 앱 복사 안내

- 검증: 집중 15개·전체 1,058개 테스트 및 구문·UTF-8 검사 통과. 로컬 실제 원고 미리보기의 320/390px 폭, 안내/닫기/복사 버튼 유지, 44px 복사 버튼, 가로 넘침 없음, 복사 성공 이후에도 안내 유지, 원고 본문에 안내가 섞이지 않음을 확인했다. 변경은 웹 안내 문구·스타일에 한정되며 PC 앱 계약을 변경하지 않았다.

- 이미지+서식을 모바일 카페 앱에 한 번에 붙여넣는 기능으로 보장하지 않는다. ZIP의 저장·압축 해제와 카페 사진 첨부는 실기기별 외부 동작이며 별도 검증이 필요하다. 브라우저 Clipboard API의 형식 제공과 받는 앱의 형식 선택은 [W3C 사양](https://www.w3.org/TR/clipboard-apis/) 참고.
- 검증: 전체 1,058개 통과, 구문 검사 완료. 실제 로컬 업체 로그인 → 미배정 프로필 카드 → 홍보 관리 → 원고 미리보기 경로, 390/320px 배치, 44px 링크·버튼과 키보드 포커스를 확인했다. 실제 내려받은 4장 ZIP은 Python `zipfile.testzip()` 통과, 사진 순서/본문 TXT와 밴드 URL 포함을 확인했다. 테스트용 업체 화면을 사용했으며 실제 카페에 게시하지 않았다. 자동화 브라우저의 클립보드 읽기는 이전 내용을 반환하므로 휴대폰 붙여넣기 검증으로 취급하지 않는다.
