# 크레 MBTI 편향 감사 및 문항 리빌드 v2.0

배포 버전: `cre-mbti-v2.0`
검토일: `2026-08-01`
성격: 공식 심리검사가 아닌 커뮤니티용 재미 테스트

## 왜 대부분 NT처럼 보였나

v1의 채점 수학 자체는 한쪽으로 기울지 않았다. 각 축에 5문항이 있어 동점이 없고, 가능한 32개 응답 조합을 전수 계산하면 양쪽 글자가 각각 16번 이긴다. 선택지 좌우 위치도 축별 2:3 또는 3:2로 섞였다.

문제는 의미와 인상이었다.

- N 선택지는 `미래 가능성·성장 흐름·라인 설계`처럼 애호가가 기대하는 방향으로 반복됐다. S는 현재 수치나 눈앞의 정보만 보는 선택처럼 좁게 읽혔다.
- T 선택지는 `근거·조건·책임·검증`처럼 유능하고 안전한 태도로 보였다. F는 감정이나 취향에 끌리는 선택처럼 보이는 문항이 있었다.
- 같은 개념을 표현만 바꿔 반복하면 실제 선호보다 크레 커뮤니티의 바람직한 답을 고르게 된다. 열성 참가자일수록 N과 T가 함께 높아지는 현상이 생길 수 있다.

따라서 v2는 점수 가중치를 억지로 조정하지 않고, 두 선택지가 같은 수준으로 책임 있고 현실적으로 보이도록 문항을 다시 썼다.

## v1 저장 응답 기준선

2026-08-01에 개인 식별값을 제외하고 v1 응답을 집계한 결과는 21건이었다.

| 지표 | 건수 | 비율 |
|---|---:|---:|
| N 결과 | 12 | 57% |
| T 결과 | 12 | 57% |
| NT 조합 | 7 | 33% |

이 수치는 `대부분 NT`라고 결론 내릴 크기나 비율은 아니다. 네 가운데 글자 조합이 비슷하게 나온다고 단순 가정할 때 NT 25%보다 높지만, 21명은 참가자 구성과 문항 효과를 분리하기에 작다. 따라서 이 기준선은 문제 제기를 확인하는 참고값으로만 보존하고, v2 점수에 역가중치를 넣는 근거로 쓰지 않는다.

## v2 설계 규칙

1. 각 축을 서로 다른 5개 행동 장면으로 측정한다.
2. 두 선택지는 모두 실제로 가능한 좋은 방식이어야 한다.
3. `합리적/감정적`, `정확/대충`, `책임/충동`처럼 한쪽에 정답 느낌을 주는 단어를 쓰지 않는다.
4. 선택지 길이 차이는 6자 이내로 맞춘다.
5. 축별 선택지 위치는 2:3 또는 3:2로 무작위 배치하고, 같은 축 문항이 연속되지 않게 섞는다.
6. 운영자가 저장한 문항은 배포 버전이 정확히 `cre-mbti-v2.0`일 때만 적용한다. 이전 관리 문항이 새 코어를 덮어쓰지 못한다.

## 축별 다섯 facet

| 축 | v2에서 분리한 행동 장면 |
|---|---|
| E/I | 생각 정리, 회복, 학습, 긴장 자극, 보상 공유 |
| S/N | 증거 확인, 변화 추적, 분류, 다음 선택 계획, 예상 밖 변화 해석 |
| T/F | 자원 결정, 조언, 의견 충돌, 경계 설명, 공동 합의 |
| J/P | 사전 준비, 경매 진행, 관리 루틴, 일정 차질, 환경 변경 |

S/N은 `현실 대 상상`이 아니라 구체 정보에서 시작하는 방식과 패턴·가능성에서 시작하는 방식을 비교한다. T/F는 `이성 대 감정`이 아니라 비교 기준에서 합의를 시작하는 방식과 사람·생활의 맥락에서 합의를 시작하는 방식을 비교한다.

## 자동 검증

`test/crewart-survey-core.test.js`가 다음을 전수 검사한다.

- 20개 문항, 축별 5개, facet 중복 없음
- 모든 문항의 두 점수가 해당 축 양극을 정확히 한 번씩 가짐
- 각 축의 가능한 32개 응답 조합에서 양극 승리 횟수 16:16
- 100회 무작위 준비에서 같은 축 연속 배치 없음
- 모든 16유형을 의도한 답으로 정확히 복원
- 금지된 정답 유도 표현과 과도한 선택지 길이 차이 없음

서버는 제출된 20개 문항 ID·축·선택 위치·득점 글자·축 합계를 서로 대조한다. 브라우저가 보낸 결과 코드만 믿지 않는다.

## 파일럿 판정 기준

초기 표본에서는 유형 비율만 보고 다시 가중치를 조정하지 않는다. 다음 순서로 원인을 구분한다.

1. 문항별 좌우 위치 선택률이 65%를 넘으면 문구·이미지·위치 효과를 검토한다.
2. 같은 축의 특정 facet만 한쪽으로 몰리면 그 장면의 사회적 바람직성을 다시 검토한다.
3. S/N과 T/F가 동시에 한 방향으로 몰리면 `가능성`, `근거`, `책임` 같은 가치 단어가 남았는지 확인한다.
4. 응답시간 중앙값이 전체의 두 배인 문항은 이해 난도나 선택지 중첩을 확인한다.
5. NT 비율이 높다는 이유만으로 점수를 보정하지 않는다. 실제 참가자 구성과 문항 유도 효과를 분리할 근거가 없기 때문이다.

이 테스트의 목적은 임상적 성격 판정이 아니라, 크레 활동 상황에서 자신이 먼저 택하는 방식을 재미있게 비교하는 데 있다.
