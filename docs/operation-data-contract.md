# 경매 운영 데이터 계약

이 문서는 채널, 개체, 방송, 캡처, 배송 기능을 수정할 때 서로 다른 기능이 어긋나지 않도록 지켜야 할 단일 기준을 정의한다.

## 1. 채널이 모든 데이터의 시작점이다

- 현재 운영 채널의 단일 기준은 `creo_v2::active_channel`이다.
- 운영 클라이언트는 저장소를 직접 추측하지 않고 `GET /api/platform/operator-context`를 사용한다.
- 응답의 `activeChannelId`, `channel`, `adapter`, `workspace`를 한 묶음으로 취급한다.
- `dataAdapter: legacy-cdcup`인 CDCUP만 기존 Supabase `items` 데이터를 사용한다.
- CREWARTS, CREYON과 이후 생성되는 채널은 `creo_v2::<channel-id>::item::*` 형식의 채널별 데이터를 사용한다.
- 새 채널 데이터를 기존 `items` 테이블에 중복 저장하지 않는다.

## 2. 개체와 방송 상태는 함께 전환한다

- 플랫폼 채널의 경매 시작·낙찰·유찰·대기는 `PUT /api/platform/channels/:id/auction-transition`만 사용한다.
- 개체 상태와 `broadcast-state`를 각각 별도 요청으로 변경하지 않는다.
- 한 채널에서 `live` 상태인 개체는 최대 한 개다.
- 새 개체가 `live`가 되면 같은 채널의 이전 `live` 개체는 `waiting`으로 돌아간다.
- 전환 성공 시 개체 상태, 활성 개체 ID, 방송 모드, 현재 채널 포인터가 같은 요청 안에서 함께 갱신된다.
- CDCUP은 호환성을 위해 기존 운영 어댑터를 유지하며 플랫폼 전환 API가 직접 수정하지 않는다.

## 3. 공통 필드 규칙

### 상태

저장 값은 아래 네 값만 사용한다.

- `waiting`
- `live`
- `sold`
- `passed`

`대기`, `진행중`, `낙찰`, `유찰` 같은 한글은 화면 표시 단계에서만 변환한다.

### 금액

- 플랫폼 API와 저장소의 금액 단위는 원이다.
- 만원 단위 입력 화면과 CDCUP 레거시 데이터 변환은 클라이언트 경계에서만 수행한다.
- 내부 데이터에 원과 만원을 섞어 저장하지 않는다.

### 식별자

- 캡처와 배송은 화면의 개체명이나 순번이 아니라 `channelId + itemId`로 연결한다.
- 이름이 바뀌거나 같은 이름의 개체가 생겨도 기존 캡처와 배송 연결은 유지되어야 한다.

## 4. 캡처와 배송

- 캡처 프로그램은 운영 컨텍스트의 현재 채널과 현재 개체를 사용한다.
- 경매 중 수동 캡처가 있으면 종료 시 같은 개체의 자동 캡처를 중복 생성하지 않는다.
- 캡처 업로드는 `channelId + itemId`를 포함해야 한다.
- 배송 페이지는 URL 또는 선택된 채널의 `channelId`로 범위를 고정하고 같은 채널의 개체와 캡처만 조회한다.
- 다른 채널의 같은 순번, 업체명, 개체명이 배송 자료에 섞이면 안 된다.

## 5. 변경 시 금지 사항

- 화면 코드에서 Supabase `items`를 새 채널의 기본 데이터로 직접 읽지 않는다.
- 활성 채널을 브라우저 로컬 저장값만으로 결정하지 않는다.
- 개체 상태와 방송 상태를 두 개의 독립 요청으로 저장하지 않는다.
- 개체명 또는 순번만으로 캡처·배송 자료를 연결하지 않는다.
- 표시용 한글 상태나 만원 값을 플랫폼 저장 형식으로 사용하지 않는다.

## 6. 배포 전 회귀 확인

다음 조건을 자동 테스트와 실제 운영 화면에서 모두 확인한다.

1. 인증되지 않은 사용자는 운영 컨텍스트를 읽을 수 없다.
2. CREYON 활성화 시 모니터, 송출, 캡처, 배송이 모두 CREYON 개체를 가리킨다.
3. CREWARTS로 바꾸면 CREYON 개체가 노출되지 않는다.
4. CDCUP은 기존 `items` 데이터와 가격 단위가 그대로 호환된다.
5. 한 채널에서 두 개체가 동시에 `live`가 되지 않는다.
6. 낙찰 전환 후 개체 낙찰가와 방송 결과 화면이 같은 값을 표시한다.
7. 다른 컴퓨터의 캡처 프로그램도 서버의 현재 채널을 따라가며 로컬 설정에 종속되지 않는다.
