# 전국크레자랑 출품 4~5마리 변경

## 적용 범위와 동작

- 전국크레자랑 지역 순환 방송의 업체별 제출 완료 기준을 4~5마리로 변경했다. 기존 5칸 예약과 제출 자료를 유지하며 별도 데이터 이전은 없다.
- 다섯 번째 개체는 선택이다. 4마리 제출 시 미등록 알림이 해제되고 수거 안내가 열리며, 기한 내 다섯 번째를 이어서 등록할 수 있다.
- 일괄 제출 화면은 4마리 미만 입력 시 안내한다. 기존 개별 저장·제출 API는 점진적인 작성을 계속 지원하지만 3마리 이하는 완료 처리하지 않는다.
- 관리자 수정 요청이 남은 개체는 4마리가 제출되어 있어도 확인 필요 상태를 유지한다. 선택 개체의 임시 저장만으로는 완료 상태를 취소하지 않는다.
- 관리자 화면은 신청 업체 수와 실제 제출 수량을 나누어 표시한다. 예약의 `quantity`와 `confirmedQuantity`는 제출 수량이 아니라 확보한 최대 자리 수다. 선택 다섯 번째 자리는 계속 확보하여 뒤늦은 추가 제출이 정원을 초과하지 않게 한다.
- 별도 정원을 지정한 회차에 4자리만 남으면 4칸으로 신청할 수 있다. 4칸 예약에서 다섯 번째 슬롯 접근은 거부한다. 기본 무제한 정원은 그대로다.
- 일반 경매의 예약 정책과 승인·경매 개체 생성 과정은 바꾸지 않았다.
