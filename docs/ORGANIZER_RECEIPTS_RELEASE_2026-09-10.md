# 주관사 수동 입금 확인 — 2026-09-10

업체를 선택하면 입금액(잔액 기본값), 입금일(한국 날짜 기준 오늘), 선택 메모와 확인 버튼이 한 팝업에 열린다. 업체의 확인 요청이 있으면 요청 금액을 기본으로 보여주며 같은 요청을 처리한다. 배송비 상세와 이력은 접힌 영역에 둔다.

- 직접 받은 입금을 누적 기록하며 구매자 결제 상태를 변경하지 않는다.
- 일부 입금은 잔액을 유지하고, 추가 입금은 별도 기록으로 쌓는다.
- 확인 완료 기록 취소는 상태·취소 시각을 보존하고 합계에서 제외한다.
- 요청 식별자 재시도는 한 번만 저장한다. 다른 창에서 금액이나 요청이 바뀌면 409로 거절하고 새로고침을 제공한다.
- 기존 업체 요청과 직접 기록을 중복 합산하지 않는다. 일부만 확인할 경우 기존 요청 금액도 보존한다.
- 주관사 전용 권한과 채널 범위를 검증한다. 경매 종료 후에도 배송비 정산은 가능하다.
- 업체 페이지는 같은 원장에서 받은 금액·잔액을 계산한다. 주관사 메모와 내부 요청 식별 정보는 업체 응답에서 제외한다.
- 수동 확인 자체로 새 문자/알림톡을 발송하지 않는다. 업체가 입금했다고 보고할 때의 기존 알림 흐름은 유지한다.
