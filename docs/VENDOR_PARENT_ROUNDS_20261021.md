# 업체 부모정보와 전국크레자랑 회차 연결

등록된 개체가 `national-cre-20261021` 같은 분리 회차에 있으면 업체 방송 달력의 부모정보 편집 화면이 해당 개체를 읽지 못했다. 조회와 저장이 모두 기존 `national-cre`에 한정돼 있었다.

업체의 공통 프로필에 실제로 연결된 전국크레자랑 회차만 조회한다. 저장할 때 회차 ID와 개체 ID를 함께 전달하고, 기존 업체 인증과 참여 권한을 다시 확인한 뒤 대상 회차의 경매 잠금 안에서 저장한다. 대상 회차의 송출 갱신 신호를 보낸다. 다른 업체·다른 행사·미연결 회차는 접근할 수 없고, 낙찰·보관·종료된 개체는 읽기 전용이다. 새 회차로 옮긴 원본 개체는 중복 표시하거나 수정하지 않는다.

이번 수정은 업체 사진·부모 이름 연결만 다룬다. 출품 편성, 업체의 원본 접수, 생일·무게·비고, 낙찰·결제·배송 내역은 변경하지 않는다.

위험도는 Release로 분류했다. 공개 응답에 회차 식별자를 추가하고, 그 회차의 개체 저장 경로를 수정한다.

- `npm.cmd run check`: 통과.
- `node --test`: 서버 전체 1471/1471 통과.
- 데스크톱 `python -m unittest discover -p "test*.py"`: 270/270 통과.
- 첫 전체 실행에서는 샌드박스가 로컬 서버 접속과 임시 파일 접근을 차단했다. 허용된 격리 테스트 환경에서 다시 실행해 위 결과를 확인했다.
- 중복·동시 요청, 낡은 버전 거절, 재시작 후 재시도, 저장 실패 후 재시도, 잘못된 회차/업체/행사, 낙찰·보관·종료, 회차 간 같은 개체 ID, 이동한 원본 중복 방지 검증.

운영 데이터로 테스트하거나 시험 사진을 올리지 않았다. 운영 배포 후에는 헬스체크·정적 파일과 기존 업체 조회만 읽기 전용으로 확인한다. 개별 업체 기기와 통신 상태는 로컬 브라우저 테스트 범위 밖이다.
