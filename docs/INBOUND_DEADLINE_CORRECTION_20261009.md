# 출품 운송 마감 및 달력 구간 수정 — 2026-10-09

위험도: Release. 업체에 표시되는 운송 일정과 달력 UI 변경이며 운송표·저장 스키마·예약·알림 계약은 변경하지 않는다.

## 재현과 수정

대구·경북, 소재지/출발지 미선택, 10/26 월요일 방송에서 도도시의 가장 이른 권역 준비일인 10/17을 빌려 표시했다. 같은 권역에는 10/20 맡기기 → 10/21 출발 → 10/25 대구 도착편도 있다. 다른 정거샵의 준비일은 해당 업체의 확정 마감일이 아니다.

- 출발 미선택 상태는 달력에 임의 마감일을 그리지 않는다. 실제 정거샵별 마지막 이용 가능편을 최대 3개 비교하고 늦은 준비일순으로 표시한다. 명칭뿐 아니라 준비일·도착일·소재지도 함께 보여준다.
- 기존 소재지 인근 후보 범위를 유지한다. 확인되지 않은 노선, 지역 기본 노선, 소재지 상충 후보는 자동 제안에서 제외한다. 모든 정거샵 목록을 통한 명시적 선택은 유지한다.
- 저장된 출발지 또는 유일하게 매칭되는 자기 정거샵은 그대로 적용한다. 방송 권역과 다른 출발지를 고를 수 있고, 방송 참여 권역은 바뀌지 않는다.
- 예: 대구·경북 방송에서도 출발지를 서울 드래곤길들이기로 직접 고르면 10/23 맡기기 → 10/24 출발 → 10/25 도착이다. 이 날짜를 대구 업체 전체의 마감으로 적용하지 않는다.
- 파르게/도도시 선은 준비일/방송일 칸의 중앙에 끝점을 둔다. 실제 도착일은 상세 정보에 따로 유지한다. 토요일/일요일과 월 경계에서 나뉘는 행은 중간 연결선으로 취급해 반으로 자르지 않는다.
- 기존 도도시 방송 당일 도착 허용, 파르게 전날 도착 기준, 휴무·지난 기한·잘못된 저장값의 확인 필요 상태를 유지한다. 날짜 클릭은 동일 계산의 상세 일정을 연다.

## 근거와 한계

- [파르게 공식 안내](https://parge.co.kr/guide): 월요일 수거/화요일 대구 도착 및 사전 접수 기준. 더 늦은 파르게 정기편이 도착 기준을 넘으면 앞선 편의 날짜는 그대로 유지한다.
- [도도시 경상 출발 → 대구 도착](https://www.dodosi.co.kr/shop_view?idx=1219): 수요일 출발 → 일요일 대구 도착, 일요일 출발 → 수요일 대구 도착의 구간 안내를 실제 페이지 이미지에서 대조했다. 같은 요일이라고 출발 당일 도착으로 계산하지 않는다.
- 실제 예약 가능 수량, 마감 시각, 현장 직접 전달 가능 여부 및 지연 여부는 운송사 확인 사항이다. 자동 예약/메시지 전송을 추가하지 않았다.
