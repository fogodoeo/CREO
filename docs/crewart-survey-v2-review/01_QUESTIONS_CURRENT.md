## Q01 — TF / JP
**밴드 경매 마감 직전! 마음에 둔 크레 2마리 중 딱 1마리만 고른다면?**

- 부모 혈통이랑 모프부터 꼼꼼히 따져보고 입찰한다
- 현재 체중이랑 먹성, 건강에 이상 없는지 체크한다
- 파업 사진 다시 보며 처음 심장 뛴 아이로 결정!
- 지금 놓치면 계속 생각날 것 같아… 원픽에 올인!

## Q02 — JP / EI
**파충류 박람회장에서 가려던 부스 가다가, 입구에 인파가 몰렸다면?**

- 원래 계획대로 돌되, 가는 길에 살짝 들러본다
- 계획했던 부스부터 다 보고 시간 남으면 가본다
- 금방 분양될지도 몰라! 일단 줄부터 서러 달려간다
- 줄 설 생각 없이 발길 닿는 대로 편하게 구경한다

## Q03 — TF / JP
**폭풍 성장한 아이의 성장 기록을 올릴 때, 썸네일로 고를 대표 컷은?**

- 핀이랑 발색이 가장 완벽하게 나온 고화질 샷
- 아기 때 쪼꼬미 시절 vs 지금 체중 비교 샷
- 손 위에서 똘망똘망 눈 마주치는 심쿵 교감 샷
- 벽에 엉뚱하고 귀엽게 착 붙어있는 엽사 샷

## Q04 — EI / SN
**새 사육장 정성껏 꾸며주고 아이를 입주시켰을 때, 내 행동은?**

- 단체방에 세팅 사진 올리고 집사들과 꿀팁 나누기
- 친한 집사에게 카톡 보내며 앞으로 키울 계획 나누기
- 사육장 앞에서 백업에 잘 적응하는지 가만히 지켜보기
- 불 끄고 은은한 조명 아래서 편안해하는 아이 감상하기

## Q05 — SN / TF
**기다리던 알에서 첫 해칭 성공! 꼬물이 실물을 볼 때 가장 먼저 보는 곳은?**

- 등 핀이랑 발색이 얼마나 예쁘게 나왔는지 살펴본다
- 난황은 잘 뗐는지, 몸은 튼튼하고 건강한지 확인한다
- 다 자랐을 때 얼마나 멋진 성체가 될지 상상해본다
- 무사히 태어나준 작은 생명이 너무 감동적이라 뭉클

## Q06 — SN / TF
**다음 시즌 사육실에서 새로운 메이팅 조합을 짤 때 내 첫 기준은?**

- 산란 주기, 해칭 성공률 같은 확실한 번식 데이터
- 부모 개체들의 실제 핀 상태와 발색 퀄리티 직접 대조
- 새로운 모프 조합이 터졌을 때 나올 멋진 비주얼 상상
- 내 취향과 사육 철학이 듬뿍 담긴 나만의 시그니처 라인

## Q07 — JP / EI
**파충류 박람회 마감 30분 전! 남은 시간 동안 나는 어떻게 움직일까?**

- 안 가본 부스 돌면서 막판 뽑기랑 이벤트 챙기기
- 여유롭게 돌아다니며 마감 시간대 북적이는 열기 즐기기
