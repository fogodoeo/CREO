## 2차 거래 흐름 반영 — 로컬 검토 대기

- 결제 방법 변경은 개인 구매자 링크에서 직접 저장한다. 결제 신고·일부 확인·완료·발송된 업체 내역은 변경을 차단한다. 기존 승인 대기 건의 검토 기능은 호환을 위해 유지한다.
- 구매자 저장 버전을 확인해 오래된 화면의 덮어쓰기를 거절한다. 같은 저장 요청의 재시도는 중복 반영하지 않는다. 변경과 업체 안내 대기열은 함께 저장한다.
- 기존 카드 안내가 있으면 구매자 화면에서 내리고 업체의 처리 필요 목록에 취소할 건을 표시한다. 업체가 외부 결제 앱에서 취소·차단 후 확인한다. 사이트가 외부 결제를 자동 취소하는 기능은 아니다.
- 새 구매자 등록에서는 인증된 개인 링크의 전화번호에 해당하는 이전 수령지를 제안한다. `이 수령지 사용` 또는 `다른 수령지`를 직접 고르며 자동 제출하지 않는다. 현재 배송업체·지점·요금을 사용하고 다른 경매의 직수령 장소는 제안하지 않는다.
- 구매자·업체 상단 이용안내를 제거했다. 업체 페이지에서만 현재 참여 업체의 이름·문의 연락처를 제공하고, 연락처 팝업은 닫기·바깥 클릭·Escape로 닫는다.
- 업체 계좌 최초 등록 화면은 설정을 먼저, 등록 이후에는 구매자 처리를 먼저 보여준다.

## 구매자 하단 메뉴 — 로컬

첫 등록은 순서대로 진행하고, 저장 이후 `내 개체 / 배송·결제` 두 메뉴를 보여준다. 배송과 결제는 같은 거래의 후속 행동이므로 한 화면에 유지한다. 내 개체에서는 현재 경매와 A/B 식별번호를 유지하고 사진이 있는 개체만 사진 보기를 제공한다. 변경 중인 정보나 추가 낙찰 미저장 상태에서는 등록 화면을 유지한다. 탭 이동 자체는 저장 요청을 만들지 않는다.

320/390/520px, 200% 확대, 최초 등록·추가 낙찰·미저장 변경·이미지 실패·포커스 복귀를 독립 로컬 브라우저에서 확인했다. 관련 단위 테스트 25개 통과. 실제 사진 API 연결과 과거 경매 통합은 별도 작업이며 운영에는 아직 배포하지 않았다.

후속 연결: 기존 결제 API의 개체·부·모 사진을 구매자·업체 공통 뷰어로 연결했다. 유효한 개인 링크는 보관된 경매의 개체와 거래 내역을 읽기 전용으로 표시한다. 사진 저장·공통 부모 참조, 장기 개인 보관함, 과거 경매 소유권 통합은 계속 별도 작업이다. 최신 검증 결과와 정확한 범위는 `PRODUCT_EXPERIENCE_RENEWAL.md`에 기록한다.

구매자 내비게이션은 로컬에서 검토할 수 있으며 운영 배포 전이다. 최초 수령지·결제 등록은 순서형 흐름을 유지하고, 등록 후에는 `내 개체 / 배송·결제` 두 메뉴로 사진·부모 정보 조회와 거래 진행을 나눈다. 업체 메뉴와 개수를 맞추기 위해 구매자에게 별도 설정 메뉴를 추가하지 않는다.
