# 전국크레자랑 업체 접속·예약 웹 적용

## 범위와 흐름

`national-cre` 플랫폼 채널 전용이며 공통 진입점은 `/vendor-access.html`이다. 기존 채널과 업체 링크는 보존한다.

문자 인증 → 업체 등록 또는 직원 참여 요청 → 업체 페이지 → 달력 예약 → 기존 출품 등록 → 예약에 개체 선택. 대표의 개인 인증 번호와 변경 가능한 업체 연락처를 분리한다. 직원은 대표 승인 후 예약·출품을 함께 관리하며 연락처·계좌·직원 승인은 대표만 변경한다.

카카오는 기존 OAuth의 검증·상태 바인딩·PKCE를 재사용하며 `returnTo=vendor`만 고정된 업체 화면으로 돌아간다. 검증된 번호는 암호화된 서버 세션에 저장하고 구매자 공개 세션에는 노출하지 않는다. 카카오 설정이 없으면 버튼을 비활성화하고 문자 인증을 제공한다. 시안의 가상 인증번호·가상 카카오 인증은 운영 코드에 포함하지 않는다.

## 저장과 권한

- 계정·소속·요청은 암호화된 `creo_vendor_access_v1::directory`에 CAS로 저장한다. 업체 생성과 채널 업체 레코드를 한 트랜잭션으로 기록한다.
- HttpOnly, SameSite=Lax 쿠키, HTTPS Secure/`__Host-` 접두사. 변경 요청은 고정 Origin과 CSRF를 검사한다.
- SMS는 3분 유효, 오입력 5회 제한, 브라우저 바인딩, 일회 사용 및 번호·접속·전체 발송 한도를 적용한다. 테스트 모드 공급자로 실제 접속을 열지 않는다.
- `va1` 접근 토큰은 업체·사용자·세션에 묶인다. 요청마다 소속/세션을 확인하고 다른 채널과 로그아웃 후 접근을 거부한다.
- 키는 `CREO_VENDOR_SECRET`(32자 이상) 또는 SQLite 영구 디스크의 `vendor-access.key`(자동 생성, 0600)다. 운영자 비밀번호를 재사용하거나 키를 DB 미러에 저장하지 않는다. **백업·복구 시 SQLite와 키 파일을 함께 보존해야 한다.** 손상된 키는 덮어쓰지 않는다.
- 기본 Origin은 `https://creok.onrender.com`; 다른 도메인은 `CREO_VENDOR_ORIGIN`으로 지정한다. 영구 SQLite/CAS 미지원 구성은 접수를 거부한다.
- 계좌 변경은 기존 vendor-directory revision 검증과 구매자 제출 계좌 snapshot 보존 경로를 사용한다.

## 예약·운영

- 월·수 20시 KST, 오늘부터 14일 이내 자동 공개.
- 회차 최소 32마리, **업체당 최대 8마리**, 지역 합산 최대 16마리. 동일 지역의 바로 앞뒤 방송 참여 금지.
- 과거 직전 방송, 미래 예약과 임시 확보를 함께 검사한다. 인접 회차의 가능한 지역 조합을 연속해서 검증한다. 이론적 수용 가능성을 확보 물량으로 표시하지 않는다.
- 신규 수량 예약은 즉시 확정. 변경 제안은 기존 예약을 유지하며 자리를 임시 확보한다. 수락 시 검증 후 이동, 거절·만료 시 임시 확보만 해제한다.
- 예약 상태·중복 요청 기록·알림을 CAS 트랜잭션으로 저장한다.
- 운영자는 날짜별 최대 수량·예약/개체 선택/직접 변경 기한·응답 시간·접수 중지를 설정한다. 기존 예약과 충돌하는 설정은 거부한다.
- 초기값: 최대 128마리(지역별 이론적 상한), 예약/직접 변경 마감 72시간 전, 개체 선택 24시간 전, 변경 응답 24시간. 실제 운영 정원은 운영자가 날짜별로 조정한다.
- 공급량 수집과 신규 임시 예약 모드는 포함하지 않는다.
- 기존 `entry-policy`를 사용하므로 신규 채널 준비 시 `open:true`로 설정한다. 예약의 개체 선택 수는 연결 개수이며 전체 정보 완성도나 경매 편성 완료가 아니다.

## 알림과 외부 설정

예약은 `broadcast_booking_updated` 한 종류로 확정·변경 제안·변경 확정·취소를 안내한다. 독촉·방송 전 알림을 추가하지 않는다. `/r/#{예약접속코드}`는 기존 업체 링크 방식이며 방송 후 30일까지 유효하다.

직원 참여 요청은 `vendor_join_requested`로 대표의 **개인 인증 번호**에 보낸다. 업체 연락처를 바꿔도 승인 수신자는 바뀌지 않는다. 승인 링크는 공통 접속의 업체 정보 화면이다.

승인된 코드·본문·버튼을 기존 `ALIGO_KAKAO_TEMPLATES_JSON`에 추가해야 한다. 설정 전에는 `configuration_pending`이며 발송 성공으로 표시하지 않는다. 기존 템플릿을 덮어쓰지 않는다. 예약 초안: `booking-alimtalk-draft.json`.
