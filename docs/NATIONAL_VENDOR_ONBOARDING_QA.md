# 업체 선택·신규 등록 검증 보고서

검증일: 2026-10-02 (한국 시간). 위험 등급: Release.
범위: 공통 로그인 이후 업체 선택, 신규 업체 등록, 중복 안내, 대표 번호 연결,
직원 승인과 기존 업체 접근의 회귀 검증.

## 적용 흐름

로그인 → 지역·업체 선택 → 목록에 없으면 새 업체 등록 →
업체명·지역·업체 연락처 입력 → 대표 연결 → 방송 달력.

대표 로그인 번호는 현재 인증된 번호로 서버가 결정한다. 업무 연락처만
다르게 입력하면 해당 번호 인증이 추가된다. 계좌 등록은 최초 등록에 필요 없다.
기존 업체 사전등록·대표 연결·직원 승인은 그대로 제공한다.
이미 연결된 업체가 하나면 재접속 시 달력으로 이동하며, 여러 곳이면 업체를 고른다.

  test/vendor-preregistration.test.js test/vendor-access.test.js
  test/vendor-access-landing.test.js test/vendor-channel-access.test.js
- npm run check: 통과.
- npm test: 909개 통과. 작업 폴더의 기존 미추적 로컬 시안 테스트 8개 포함.
- 데스크톱: python -m unittest discover -p "test*.py" — 203개 통과.
- 데이터 검증은 임시 DB·가짜 SMS·가짜 번호만 사용. 운영 경매 기록에 테스트 쓰기 없음.
- CSRF, 비로그인 접근, 다른 업체 접근, 대표/직원 권한, 현재 인증 번호,
  중복 요청·동시성, 재시작, 인증 만료, 저장 실패 후 복구를 포함한다.

## 화면 검증

better-interface 및 accessibility/layout/writing/typography/colors/UI 기준을
기존 HTML/JS/CSS에 적용했다. 저장소 AGENTS.md의 모바일·인코딩 지침을 따랐다.

- 390px: 업체 목록, 지역 선택, 신규 등록 폼, 중복 에러와 복귀, 등록 후 달력 확인.
- 320px: 등록 폼의 문서 너비와 스크롤 너비 모두 320px. 등록 버튼 접근 가능.
- 연락처 변경 시 버튼이 연락처 인증으로 바뀌고, 원래 번호로 복귀하면 등록하기 표시.
- 신규 등록 후 재접속 시 해당 업체 달력 자동 진입 확인.
- 업체 정보 → 업체 선택 → 다른 업체 찾기 경로 확인.
- 키보드 Enter로 등록 화면 진입, Tab으로 업체명 → 지역 이동 확인.
- 입력 글자 17px, 입력 높이 56px, 주 버튼 높이 54px, 보조 링크 44px.
- 렌더링된 색상 대비: 입력 14.40:1, 보조 문구 5.26:1, 주 버튼 5.08:1.
  지역 선택 포커스 테두리는 3px, 인접 입력 배경 대비 5.66:1.
- 불필요한 최초 역할 선택과 반복 필수항목 설명 대신 입력 레이블·상황별 버튼 사용.

검증한 범위에 남아 있는 차단 문제 없음.
실제 iOS/Android 기기의 가상 키보드와 화면 낭독기, 실제 SMS·알림톡 수신은
이번 테스트에서 검증하지 않았다. 직원 승인 알림은 기존 알림 설정에 의존한다.
회차별 결제·정산 데이터 분리 및 정산 날짜 선택은 별도 작업이며 이번 변경에 포함하지 않는다.
