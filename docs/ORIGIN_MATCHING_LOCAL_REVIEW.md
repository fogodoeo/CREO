# 출발 정거샵 자동 연결·추천 검토

2026-10-05 · 로컬 4359 · 운영 미배포

## 반영한 흐름

1. 직접 저장한 출발지가 있으면 그대로 사용한다.
2. 없으면 업체명·지점명·소재지를 대조해 자기 정거샵을 표시한다. 같은 상호의 여러 지점이 남으면 자동 연결하지 않는다.
3. 자기 정거샵을 특정할 수 없으면 업체 소재지 기준 후보를 최대 3곳 표시한다. 업체가 골라야 마감일이 표시된다.
4. 소재지를 알 수 없으면 시·군·구를 선택하거나 전체 정거샵 목록에서 직접 고른다.
5. 선택을 저장하면 목록을 접고 선택한 출발지에 초점을 돌려준다. 다른 정거샵으로 변경 가능하다.

방송 권역과 배송 출발지는 독립적이다. 서울 업체도 가까운 경기 정거샵을 선택할 수 있지만 방송 참가 지역·회차·권한은 변경되지 않는다.

## 자료와 추천 기준

- 파르게 [공개 정거샵 목록](https://parge.co.kr/api/partners)의 활성 지점 109곳과 기존 지역 기본 노선 4개를 연결했다. 이미 확인한 지점별 수거 예외를 유지한다.
- 도도시 기존 대구행 출발 지점 98곳에 [공개 위치 목록](https://www.dodosi.co.kr/118) 75건의 이름·주소·좌표를 대조했다. 지도에서 특정되지 않는 지점은 운송표에 적힌 도시 수준으로만 취급한다.
- 같은 시·군·구, 같은 도시를 우선하고 이후 확인된 지도 지점의 인근 후보를 사용한다. 도시 수준의 추정 위치만 있는 다른 도시 지점을 거리순으로 올리지 않는다.
- 추천 기준점은 업체 소재지의 행정구역과 공개 지점 좌표를 이용한 근사값이다. 업체의 정확한 좌표·도로 이동거리·교통시간을 계산한 결과가 아니며 km 수치는 표시하지 않는다.
- 베누스게코·산타게코는 운송표의 구 이름과 공개 지도 주소가 달라 자동 연결·추천에서 제외했다. 다른 도시의 동명 지점 좌표를 가져오는 경우도 차단했다. 전체 목록에서 사용자가 직접 선택하는 경로는 유지했다.
- 업체 주소를 외부 지도 서비스로 전송하지 않는다. 업체 방송 응답에는 상세 주소 대신 시·군·구 정보만 추가한다. 정거샵 자동 매칭은 로그인 권한이나 업체 소유권을 연결하는 기능이 아니다.
