# 업체 등록 안내와 간소화 — 2026-09-14

사용자 요청: 9월 17일 크레용 출품 접수, 하단 미등록 표시, 개체 등록 항목 축소.

## 반영 내용

- 업체 정보: 연락처·은행·계좌번호·예금주가 모두 저장되면 등록 필요 표시를 지운다. 입력 중인 폼을 완료 상태로 취급하지 않는다.
- 출품 개체: 현재 경매의 접수가 열려 있고 저장한 출품이 0개일 때 표시한다. 다른 경매·업체의 출품을 합산하지 않는다. 접수 마감 후에는 등록을 요구하지 않는다.
- 선택 메뉴의 파란색과 구분해 작은 표시와 `등록 필요` 문구를 쓴다. 메뉴 아이콘은 표시 유무에 관계없이 수평 정렬한다.
- 개체 사진 영역은 유지한다. 성별·체중·부모 정보·해칭일·비고를 모두 펼친다. 개체의 별도 모프·크기 입력칸과 모프 필수 검사를 제거한다.
- 피들 가져오기는 모프를 비고 첫 줄에 포함한다. 비고는 기존 600자 제한을 적용한다. 재시도 시 중복 생성하지 않으며 업체가 비고를 수정할 수 있다. 기존 구조화된 모프·크기 자료는 보존한다.
- 운영자가 승인한 비고가 경매 개체에도 저장되도록 연결했다.
- 낙찰·정산 메뉴는 기존 응답에 포함한 작은 출품 요약을 사용한다. 이 요약은 사진 URL 발급·추가 미디어 요청을 하지 않는다. 요약 조회 실패가 결제 화면을 차단하지 않는다.

직수령: 크레용 대구본점·양산·부천·과천·대전, 오늘도마뱀 김포본점·양주.

P1 진행자: 김동욱 / 크레용 대구본점 대표. CDCUP의 P1/P2 배치와 공용 배너 4개(옹동2·파르게·놀크레·크레오)를 적용했다. 팀·P3·낙찰·배송 기록은 복사하지 않았다. 방송 활성 채널은 `creyon`을 유지했다. 업체 초대 메시지는 발송하지 않았다.
