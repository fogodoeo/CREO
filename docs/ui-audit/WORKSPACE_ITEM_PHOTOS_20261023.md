# 관리자 개체 특성·사진 편집

위험도: Release. 관리자 전용 사진 업로드/조회 경로와 개체 저장 전 준비 단계를 추가한다. 기존 비공개 출품 사진 저장소·코덱·회차/버전 검사·중복 요청 보호를 재사용한다. 운영 자료를 이용한 쓰기 검증은 하지 않는다.

## 반영 범위

- 기본 입력에서 성별·체중·출생일을 수정한다. 사진·부모 정보, 경매 설정, 낙찰 정보는 펼치기로 구분한다.
- 개체/부/모 사진을 파일 선택으로 추가하고 저장 전에 미리 본다. 사진 빼기와 해당 종류의 변경 취소를 제공한다.
- 사진 선택·닫기 자체는 업로드하지 않는다. 명시적 저장에서만 압축/업로드하고 모든 사진 준비 후 버전이 맞는 개체에 연결한다.
- 업로드 응답 유실 시 같은 파일 식별자/내용으로 재시도하고, 개체 저장 재시도에서는 이미 올라간 사진을 재사용한다.
- 사진 확대는 원본, 목록은 썸네일을 사용한다. 읽기/이미지 오류의 재시도와 비동기 로딩 후 키보드 초점 유지, 종류별 파일 입력 이름을 제공한다.
- 특성 변경은 기존 시트·경매·구매자 정보의 표현을 함께 갱신한다. 수정하지 않은 옛 형식의 값과 부모 사진 메타데이터는 보존한다.

## 남은 한계

- 최종 개체 저장 전에 창을 강제 종료하면 미연결 비공개 파일이 남을 수 있다. 경매 개체에는 연결되지 않으며 기존 사진 저장량/미사용 파일 점검 대상이다.
- 모바일 320px와 주요 키보드 동작을 검증했지만 전체 화면 낭독·200% 확대·모든 브라우저 파일 코덱의 검증은 별도 남아 있다.
- 운영 서버에서는 실제 데이터 변경 없이 배포 파일·사진 조회·편집창 표시와 회차 데이터 보존만 확인한다. 전체 역할 UI/UX 작업 완료를 뜻하지 않는다.
