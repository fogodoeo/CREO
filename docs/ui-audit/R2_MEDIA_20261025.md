# R2 media preparation — 2026-10-25

Status: **R2 provisioned and bundled site media copied; production not switched**.
Risk classification: Release (storage and public media serving).

## Implemented

- Official pinned AWS S3 client/presigner for private R2 object storage.
- Existing entry-photo references, owner checks and expiring app signatures survive
  switching stores. R2 read URLs are signed locally; image bytes bypass Render.
- Broadcast assets, logos/posters, capture shares and repo media support R2.
- Strict public namespace/origin mapping without changing durable auction rows.
- Resumable source inventory/copy/byte verification, source originals retained.
- Read-only rollback mode preserves new R2-only images; capture overrides remain
  tied to the backend that received the rollback write.
- Legacy CDCUP browser uploads retain their existing path: its vendor mode does
  not carry an operator session. Sending those uploads to an admin-only API would
  break vendor registration. This path and DB-inline media need a separate audit.
