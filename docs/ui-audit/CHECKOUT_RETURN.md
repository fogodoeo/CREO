# 외부 페이지에서 거래 화면으로 돌아오기

2026-09-12. 직전 목표 턴은 `df3b479` 운영 배포와 실제 검증으로 progress였다. 이번 단계는 아래 재현과 수정, 기존 경매 원장의 읽기 전용 집계로 progress다. 전체 목표는 계속 진행 중이다.

## 재현

구매자 배송·결제, 업체 낙찰·정산, 이전 구매자 수령 입력, 이전 업체 현황의 네 HTML 모두 `pagehide`에서 갱신기를 정지한 뒤 다시 시작하지 않았다. Chrome이 BFCache로 화면을 복원하면 페이지 스크립트를 처음부터 실행하지 않으므로 결제 앱/다른 페이지에서 뒤로 돌아온 후 상태 갱신이 멈췄다.

실제 Chrome에서 `pageshow.persisted=true`를 확인했다. 수정 전 네 화면 모두 복귀 후 조회 증가 없음, 수정 후 네 화면 모두 조회 재개 및 다른 창에서 바뀐 수령지 표시를 확인했다. 가상의 경매·구매자만 있는 실제 API+임시 SQLite를 사용했다.

## 변경

- 공통 갱신기가 pagehide 동안 멈추고 pageshow 복귀 시 다시 조회한다. 실제 종료용 stop은 이벤트와 타이머를 해제한다.
- 창 포커스·탭 표시·BFCache 복원이 겹쳐도 하나의 요청만 실행한다. 진행 중 요청 이후 필요한 갱신을 한 번 이어 간다.
- 오래된 revision 응답은 중단 후 상태 문구를 바꾸지 않는다. 저장이 시작된 뒤 늦게 도착한 revision으로 새 전체 조회를 시작하지 않는다.
- 기존 초안 보호와 가벼운 revision 조회 간격을 유지한다. 새 주기적 전체 경매 다운로드를 추가하지 않는다.
