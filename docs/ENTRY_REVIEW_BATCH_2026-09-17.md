# 출품 검토·편성·식별 라벨 — 2026-09-17

출품 선택 → 편성 → 교차 배치 → 라벨 출력 흐름을 구현하고 격리 자료로 검증했다. 실제 출품 승인·순서 변경, 알림 발송, 종이 출력은 수행하지 않았다. 운영 배포 결과는 배포 후 별도로 확인한다.

## 확정한 흐름

1. 검토 대기 목록에서 개체를 체크한다. 정보는 `암컷 28g · 아토 × 미운 · 해칭일 · 비고` 순서이며, 없는 항목은 표시하지 않는다. 긴 내용은 한 줄 말줄임하고 상세에서 전체를 확인한다.
2. `1부 / 2부 / 이벤`을 선택하고 `선택 출품하기`를 누른다. 선택한 개체만 한 트랜잭션으로 경매 대기에 반영한다.
3. 번호는 각각 `1부 A01`, `2부 B01`, `이벤 E01`부터 부여한다. 기존 A/B 및 팀 번호를 자동 변환하지 않는다.
4. 편성 완료의 `업체별 교차 배치`는 선택한 부 전체를 대상으로 업체 순서를 무작위로 정한 후 업체마다 한 마리씩 반복 배치한다. 업체별 수량이 다르면 남은 업체의 개체를 이어 배치한다. 업체 내부의 기존 순서는 유지한다.
5. 이미 부여한 식별 번호·개체 ID는 유지하고 숫자 진행 순서만 바꾼다. 같은 요청을 재시도해도 재편성하지 않는다.
6. 체크한 개체의 `식별 라벨`에서 50×30mm 미리보기와 B1 PRO 출력 버튼을 제공한다. 미편성 개체는 기존 출품 번호를, 편성된 개체는 전체 식별 번호를 사용한다.

출품 직후에는 방금 편성한 개체의 선택을 유지한다. 교차 배치 후에는 해당 부가 선택되어 다시 체크하지 않고 라벨로 이어진다. 불가능한 작업 버튼은 비활성화하고, 처리 결과는 목록 위에 표시한다. 2부나 이벤트를 먼저 편성한 후 1부를 추가해도 해당 부 위치에 삽입한다. 뒤 순서 중 입찰·낙찰 기록이 있으면 순서를 밀지 않고 거절한다.

라벨은 업체명 → 식별 번호 → 성별·체중 → 등록된 부모 이름 → 원래 출품 번호 순서다. 부모 둘 다 있으면 `아토 × 미운`, 한쪽만 있으면 `부 아토` 또는 `모 미운`이다. 승인된 부모 연결을 기준으로 현재 부모 이름을 읽는다. 출력을 누르기 전 최신 정보와 대조하여 변경되었으면 다시 열도록 안내한다.

미리보기 이후 편성 순서만 바뀐 경우도 출력 전에 거절한다. 재배치 버전은 이전 시간보다 반드시 증가시켜 같은 순간에 연속 변경되어도 오래된 목록이 통과하지 않는다.

## 보호 조건과 검증

위험도: release. 승인 저장·번호·진행 순서·웹/PC 프린터 계약에 걸친 변경이다.

- 중복 요청, 다른 본문으로 같은 요청 ID 재사용, API 인스턴스 간 동시 승인, 버전 충돌, 다른 경매·업체 혼입을 검증했다.
- 임시 SQLite에서 저장 중 실패 시 업체별 출품 자료와 경매 개체 모두 롤백되는지, 재시작 후 재시도 가능한지 검증했다.
- 진행 중 경매는 일괄 편성을 거절한다. 입찰 기록·낙찰 정보가 있는 개체, 보관 경매, 변경된 목록은 교차 배치를 거절한다.
- 번호가 공개 방송 데이터, 구매자 표시, 구매자·업체 낙찰 안내 변수까지 그대로 유지되는지 가짜 발송 제공자로 검증했다. 실제 발송은 없다.
- PC의 실제 큐 어댑터에 식별 라벨 형식과 부모 이름이 보존되는지, 배송 라벨의 기존 형식이 유지되는지 검증했다.
- 한글 번호를 공백으로 잘라 `1부`만 인쇄하던 가능성을 수정했다. 열전사 폰트에 없는 가운데점·곱셈 기호는 출력에서 `/`, `X`로 표현한다.

## 화면 검토

better-interface의 접근성·레이아웃·문구·타이포그래피·색·UI 여섯 영역을 검토했다. 기존 중립색/파란색 체계를 유지하며 새 애니메이션은 추가하지 않았다.

| 영역 | 확인과 반영 |
| --- | --- |
| 접근성 | 체크박스·버튼 이름, 전체/부분 선택, 키보드 Escape 및 포커스 복귀 확인 |
| 레이아웃 | 목록 위에 일괄 작업 배치, 320/390px 및 기본 PC 폭에서 가로 넘침 확인 |
| 문구 | 개체 정보 대신 실제 성별·체중·부모 이름 우선, 없는 정보 안내 문구 생략 |
| 타이포그래피 | 한 줄 요약과 보조 업체/번호 구분, 긴 비고 전체는 상세에 보존 |
| 색 | 선택 배경/체크와 텍스트를 함께 사용, 기존 파란색 주요 행동 유지 |
| UI | 전체 선택 시 체크 표시 갱신, 팝업 바깥 클릭 닫기, 경매 전환 시 선택과 부 초기화 |

로컬 실제 브라우저에서 체크 일괄 승인, 2부 번호 부여, 업체 교차 배치, 새로고침 후 유지, 선택 없을 때 오류, 긴 비고 상세, 부모 이름 유무, 라벨 미리보기, 다른 경매의 빈 목록을 확인했다. 320px 라벨 미리보기에서 발견한 위아래 잘림은 비율에 맞춘 레이아웃으로 수정했다. 검사한 화면에서 콘솔 오류는 없었다.

최종 흐름 재검증: 2부 2마리 출품 → 나중에 1부 4마리 출품 → 1부가 2부 앞에 배치 → 업체 교차 배치 → 해당 4마리 선택 유지 → 라벨 4장 연결. 추가 체크 없이 출력 준비가 이어졌고 390px에서 가로 넘침이 없었다.

판정: 로컬 사용자 검토 가능. B1 PRO 비트맵은 576×360으로 생성하여 시각 확인했지만 실제 종이 출력은 미실시다. 확인 시점에 로컬 17876 프린터 연결 서비스가 응답하지 않았다. B1 직접 출력에는 변경된 PC 앱 실행과 프린터 연결이 필요하다. 브라우저 인쇄는 50×30mm·배율 100%·머리글/바닥글 끄기를 사용하며 실제 드라이버 출력은 별도 확인 대상이다.
