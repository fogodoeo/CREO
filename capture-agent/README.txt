CREO 캡처 에이전트 설치

1. PRISM Live Studio 설정 > 단축키에서 "출력 스크린샷"을 Ctrl+Shift+F12로 지정합니다.
2. PRISM 설정 > 출력 > 녹화 저장 경로를 확인합니다.
3. install.bat을 실행합니다.
   - Python 3가 없으면 winget을 통해 사용자 계정에 자동 설치합니다.
4. 설정창에서 CREO 서버 주소, 캡처 토큰(또는 관리자 비밀번호), PRISM 저장 폴더를 입력합니다.
   - 경매 채널은 auto로 두면 현재 활성 경매를 자동으로 따라갑니다.
   - 여러 컴퓨터에 설치한 경우 실제 송출 본체에서 "이 PC를 활성 본체로"를 누릅니다.
5. 연결 테스트와 캡처 테스트를 각각 누릅니다.
6. 성공한 뒤 저장하면 Windows 로그인 시 자동 실행됩니다.

설정값은 코드에 고정되지 않습니다. 바탕화면의 "CREO 캡처 설정"에서 다음을 변경할 수 있습니다.
- 자동 캡처 ON/OFF
- 서버 주소와 채널
- 본체 이름
- PRISM 스크린샷 저장 폴더
- 스크린샷 단축키
- 캡처 지연과 서버 확인 간격
- 사진 최대 크기와 WebP 품질
- 크롭 영역(X, Y, 가로, 세로 %)

캡처 실패는 낙찰 처리를 막지 않습니다. 배송페이지에서 오류 상태를 확인하고 다시 촬영할 수 있습니다.
