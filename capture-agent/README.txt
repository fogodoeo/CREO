CREO 캡처 에이전트 v1.2.1 · Python 불필요

1. PRISM Live Studio 설정 > 단축키에서 "출력 스크린샷"을 F3으로 지정합니다.
   - F3을 "녹화 시작/종료"에 지정하면 이미지 파일이 생기지 않아 캡처 에이전트가 실패합니다.
   - F3은 반드시 정지 이미지가 저장되는 "출력 스크린샷" 기능이어야 합니다.
2. PRISM 설정 > 출력에서 스크린샷 저장 경로를 확인합니다.
3. 이 폴더의 INSTALL.cmd를 더블클릭합니다.
4. 설정창에서 아래 값을 확인합니다.
   - 서버 주소: https://creok.onrender.com
   - 경매 채널: auto
   - 캡처 토큰 또는 관리자 비밀번호
   - PRISM 저장 폴더: 자동 찾기 후 실제 폴더와 다르면 선택
   - 단축키: f3
5. "진단"을 눌러 서버·폴더·인증·단축키 상태를 확인합니다.
6. "캡처 테스트"를 누르면 F3을 전송하고 새 이미지가 생기는지 확인합니다.
7. "이 PC를 활성 본체로"를 누르고 저장한 뒤 설정창을 닫습니다.

문제가 생기면 바탕화면에서 확인
- CREO Capture Diagnostics: 현재 설정과 서버 연결을 즉시 진단합니다.
- CREO Capture Log: 상세 실행 로그를 엽니다.
- CREO Capture Status: 마지막 성공·실패 단계와 오류를 엽니다.
- CREO Capture Folder: 설치·로그·진단 파일 폴더를 엽니다.

로그에 남는 단계
- 에이전트 시작과 설정 상태(토큰 원문 제외)
- 서버 연결과 작업 폴링
- 경매 캡처 작업 수신
- F3 전송
- 새 이미지 파일 경로와 크기
- WebP 압축 결과
- 서버 업로드 성공 또는 정확한 실패 사유

캡처 실패는 낙찰 처리를 막지 않습니다. 실패 작업은 서버에 오류로 기록되며 다시 촬영할 수 있습니다.
